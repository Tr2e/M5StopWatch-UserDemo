# 参考模型制作 Pipeline

适用于以既有实物／设定为目标的模型制作。硬表面机械模型可直接执行；人物、软体等仍可沿用参考、比例和验收节点，但需在 G0 换成适合的雕刻、拓扑、绑定工具，不强套程序盒体。目标是可追溯地收敛到约定外观，不承诺仅凭名称就能精确复刻任何对象。

## 执行规则

同类任务已有用户接受的资产时，先查看其关键返工记录、对应实现与前后图，在本次卡中说明哪些方法适用、如何落实；不照搬另一型号的尺寸。

**交付质量要求：灰模和粗模是内部制作阶段，不是默认交付物。** 除非用户明确要求看草稿，否则必须自主完成下面的比例、结构、局部和生产显示检查，再交付模型。进度更新可以说明返工发现；不能把已知脸部不对、比例不对或装配错误的版本改称“候选版／待用户验收”后结束工作。最终用户验收用于确认预期，不负责替代理本应完成的找错与精修。

本流程直接吸收 RX-78 R2–R5 与牛高达 R1→R2 的实际返工。下列节点中的校准动作是执行要求，不是可选的历史阅读。沿用的是方法，不是另一型号的尺寸、槽数或形状。对其他类型模型使用对应的关键部件；不适用项需给出结构依据。

每个模型一份制作卡、独立版本证据目录。节点记录：输入、可编辑产物、检查画面、具体结论、状态、检查人、修复和退回点。共用模板见 `../assets/model-card.md`；RX-78 实例在仓库 `docs/Gundam-Museum-RX78-Pipeline复盘.md`。

状态使用 `未开始 / 制作中 / 待证据 / 自检通过 / 返工 / 用户已验收 / 不适用`。自检通过必须有实际看过的证据及具体判断；用户已验收必须引用用户原话和对应版本。不适用须说明理由，例如静态资产无需关节动作，不能用来跳过困难节点。

内部节点自行检查、修复、继续，不默认逐节点等用户批准。阶段更新给出当前产物、主要差距和下一步；仅在关键版本／预期无法合理确定时提问。用户要求阶段审阅则遵循其节奏。只有达到文末“交付前视觉复核”的版本才能交付候选版，并将用户视觉验收留为待验，不伪造通过。

门槛在制作卡中具体化：对有可靠依据的比例记录目标区间、依据和当前值；对开口、连接、分件记录明确结构关系；对视觉判断记录部位、视角和偏差。不要统一编造“95% 相似”或固定尺寸容差。版本错误、关键辨识点错误、约定视角明显缺件／穿透属于阻断项；原生画面不可辨的微小刻线可按预算简化并说明。阻断项清零且必需证据齐备，才能自检通过；缺参考不算零偏差。

## SD 高达执行路径 · RX-78 v1–v5 经验必须在制作前落实

适用于新 SD 高达与现有 SD 模型返修，和下方通用 G0–G7 一起执行。当前质量与产品行为基准是 **SD RX-78 v5**，不是曾被退回的 v1/v2，也不是 HG RX-78 的旧比例。完整错误溯源见仓库 `docs/Gundam-Museum-SD-RX78-Pipeline复盘.md`；**下列检查本身就是执行规则，无需等用户再次指出错误或翻历史才能启动**。

新模型顺序：锁参考 → 定比例与关节 → 无装备整体体积 → 头脸天线 → 胸肩四肢与细节 → 完整装备站姿 → 生产显示 → 已授权的设备交付。每个小步完成即自查，未通过留在该步；最终仍按 G6 再看一遍全部成品。返修从受影响节点开始，已认可且未受影响部件保留。

### SD / G0–G1：先锁定每张图的用途

- 区分 SDEX、SDCS 的 SD/CS 骨架、BB 等版本；未确认图片出处就记录推断，不能把外观相近写成同一官方型号。禁止压短 HG 身体后沿用旧脸，也不能把 RX-78 的全部尺寸移植给另一台。
- 每张参考标记为：**比例基线、结构依据、姿态依据、配色依据、仅问题提示**，允许多用途，但须分别有依据。用户补图只指出问题时不得从中拿尺寸或替换版本；用户明确指定姿态时，只更新姿态合同。后续同款官方多角度资料补足深度与连接，不覆盖用户明确指定的正面基线。
- 开工前实际看同构型正/斜/侧/背、头脸近照、说明书/板件/拆甲及武器背面连接；主参考之外至少两张有效成品图交叉核对，转载同图不算新来源。记录看不见处、照片估计和实测数据的区别。
- 保存原图、来源、用途、哈希、当前代码/生产图。基线改变时明确撤回哪些旧比例/外观结论；技术测试记录保留，但不继承为新图外观通过。

### SD / G2：把比例、体积、关节和空区分开建表

- 比例分母固定：例如不含 V 翼、枪盾及散置配件的冠顶到脚底 H；记录头宽高、肩宽、胸宽高、颈部露出、腰裙、髋膝踝、单脚宽高与朝向。头大身小可能是胸肩偏小、颈长、脚窄的组合问题，不能一律缩头或继续压腿。
- 图像比例与三维量分列。照片只允许有记录的等比缩放/平移/裁剪；不同姿态/透视先解释，再改几何。不把照片修正百分比直接乘入模型，不以单个“三维几头身”代表正面吻合。
- 另列头壳、胸壳、肩甲、前臂、腰裙的前后截面、最大截面位置和收口。再列眉檐—眼窝—面罩—颊框深度、胸栅凹腔、颈口、膝轴、踝口、枪柄握孔、盾背支架。
- 建立髋→腿→踝/脚、肩→上臂→肘→前臂→腕/手→枪的层级；盾板→支架→前臂接口独立描述。成品位置、说明书零件和代码语义对应后再建模，关节/锚点不从参考的二维坐标直接猜成世界坐标。

### SD / G3：整体先同时通过正面比例和侧面体积

- 无装备灰模检查正、左右斜、左右侧、背面；同相机新旧对照。分别记录“比例通过”和“体积通过”，两项都通过才进入局部精修。
- 头身、宽肩、短颈、胸腹、裙甲、短肢和宽扁足按本款基线协同调整。腿长或脚窄的问题先分清比例与脚朝向；修改髋高须同步上身/关节/装备锚点，不能剪切整个网格。
- 后脑不能只有正面合格：查中段体积、顶部与底部收口、颊框到后壳的连续曲率，不能留扁片或柱状后脑。正面宽高相同也要看侧面。
- 胸甲不能只是变宽的平盒：按真实折线布置变化截面，检查胸中段厚度、中央胸块前凸、肩线收口、颈圈宽度及回折。肩壳、前臂、腰裙也必须在同轮补齐体积，不能只把头做厚。
- 先安排目标站姿的大关节，再检查无装备整体，随后装回枪盾核对包络。双足具有共面的实际接触面，不能只有鞋尖着地。

### SD / G4：头脸与天线独立过关

- 隔离头部，在固定正/斜/侧面核对：眼区高度和外跨度、眼角、眉檐位置、面罩宽高、下巴长度、口槽数量、红额片轮廓、摄像窗及颊槽。SD 宽眼不能变细长护目镜；微调眼睛时同时查眉檐和下巴，不靠放大眼罩补辨识度。
- “脸像凸出头盔”先查实际深度和装配：面罩位于颊框围合开口内，眼窝在眉檐后。按本款侧面参考验证前缘关系；RX-78 的探针坐标不能直接用于别款。禁止用拉远/改俯仰掩盖凸脸。
- **嵌入式大眼**：用户指定大眼时保留其比例，不能靠缩眼消除“贴面罩”感。建立口沿→内壁→镜片斜边的连续几何，镜片退在口沿后，下面罩回接下眼眶；黑底叠彩片不能代替凹腔。检查完整头部对镜片中心与接近四角的遮挡，不能只测中心或仅过滤眼件。两侧斜视及仰/俯近景专查眉檐压上角、颊甲伸入外眼角；发现后移动遮挡边界并回接，不能前移镜片掩盖。增加镜片前移和额外盖面遮眼负例，几何检查仍需配合原生静止/旋转审阅。命运与强袭 v3 回查实际暴露了中心采样漏检，见 `docs/Gundam-Museum-SDEX-v3-嵌入式大眼.md`。
- **头脸、眼窝、镜片分开验收**：面罩在眉檐后只证明整脸前后关系；还要独立确认口沿、向内的四壁/环壁、镜片支撑与下眼眶回接。黑色底板上叠彩色片，即使整组藏在头盔内，也不是凹入眼窝。已获用户认可的脸型/大眼轮廓保留，不能为了复用四角助手把RX-78五边形大眼改成另一款梯形。眼部精修不授权改变整体头身比例。
- **单眼窗口不是接缝**：区分黑材质、真实眼腔与背景洞。按同款参考记录中央及两侧开口轮廓/高度、上眉檐和下面具、镜片直径/位置与支撑；不能将“斜眼窗”实现为沿眉檐等厚偏移的黑线。沙扎比保留自己的斜窗，不能套扎古水平眼带或双眼比例阈值；绿色额头摄像窗与真正单眼分开标记，不能用“头上存在绿色像素”作为单眼可见性检查。
- **深度与容纳关系用本款局部坐标**：镜片应在窗口口沿后、腔底前；检查中心与周界，记录允许的眉檐遮挡和异常甲片侵入。曲面口沿按对应位置/局部法线测深，不能拿两处不同XY的Z数值相减冒充退入深度。单眼须核对圆片在窗口中的容纳与原生100%/65%下可辨性，不靠外移镜片或放大绿点补救过窄眼缝。
- **经验回查不等于自动全馆通过**：新眼窝测试明确列接入机体及覆盖范围。对历史资产回查时保留问题基线和用户认可范围；没有凹腔范围、近角点/周界遮挡及受控前移/盖面负例的旧测试，只能保留为原有检查结果。2026-09-15 RX-78、ν、沙扎比三台均通过旧864组测试但仍检出眼区问题，见 `docs/Gundam-Museum-三机眼部专项检查-20260915.md`；这是已知待修问题，不能记为已修复经验。后续改眼窝时要重跑头/面具支撑链，避免为消除贴片感又造成悬空。
- **换眼窗要拆掉旧接边**：新下眼框不能叠在旧面具顶缘上形成第二道嘴形折线；优先共享边界和中央脊，明确面具后梁仍连接。曲面到硬脊的过渡若用非共面四边形出现交替三角明暗，应检查面划分和折脊方向，不用加细分/涂黑遮掩。沙扎比返修改用沿曲线到中央脊的三角扇及左右平面薄壳，面数几乎不增。逐台修复记录见 `docs/Gundam-Museum-三机眼窝优化-20260915.md`；历史问题审查仍作为旧版证据保存。
- 红额冠不能穿眉檐；前摄像窗不能被额片遮住，后窗不能埋进后壳；跨头顶冠带需回接壳体，不能成为悬空拱桥。每次改额冠或后脑都重新看这些连接。
- V 翼分别校跨度、上扬角、根部宽度、中段/外段宽厚递减及端面。尖锐程度服从本款最新基线：玩具小钝端不等于整支等宽等厚，尖端也不等于针状过细。以多个真实截面和正斜侧图验证，不能只检查两个端点或只检查末端不是单顶点。
- 局部通过后回看全身和低档原生图。数值在区间内、正面好看、测试通过，都不能抵消侧面失真。

### SD / G5：完成胸甲细节、目标站姿和真实装配

- 胸栅外框回接蓝胸，百叶置于凹腔内并有深度间隔；检查旧胸面没有封槽。检查膝轴与小腿上沿、开放踝甲与鞋面的间隙，避免穿插条纹。后窗、颈圈、额冠、薄边和内壁按低俯仰复查，黑贴片不能替代真实凹腔。
- 目标站姿用关节刚体旋转：按图确定肩肘腕夹角、双脚外展、左右及前后差、盾板倾角。前臂必须绕肘转，不能只改肩轴或单独挪手；脚/踝配套变换并保持接地。轻微不对称要有姿态依据，不能随机扭身。
- 手掌握孔和枪柄共用装配坐标；手腕连接前臂，枪身同时避开前臂。盾板必须在肩臂外侧，经可见支架连接到接口；不能把枪盾平移成悬浮件，也不能为避免穿模把持盾手永久遮住而违背目标姿态。
- 肩载护盾、腰挂／背挂武器也属于完整装备，而不只是手持件：各自保留独立面范围，检查附件—本体相交及受控错误负例；背面与侧面必须看见实体后壳、挂点或支架连续性。孤立附件图只能核形，不能替代完整前后斜视中的装配验收。
- **完整装备网格做独立相交检查**：附件对全部相关身体部件及其他附件；不能用无装备图、单武器图或剔除开关零差异替代。正常插接只允许明确的接口小范围，记录允许接触与非预期相交，禁止整对部件豁免。用已知穿模旧版/受控错误输入验证检测确实能失败。
- 写明检测覆盖边界：非共面面片穿越不等于共面接触、完全包含或全关节运动包络。适用时补距离/体积检测；所有模型都补看完整装备旋转及握持、盾背组合近景。过滤遮挡部件的诊断图须标注，不能替代完整场景。
- 改厚度、肘腕、枪位、盾角后，上述装配检查和下游显示检查立即失效，必须重跑；头部受肯定不代表身体/装备已经验收。

### SD / G6：四项独立签结论，禁止用一种通过替代另一种

分别填写：**比例与轮廓、侧面体积与局部层次、装备/接地、生产显示**。每项列最终源版本、实际看过的图、检查方法与结果，仍有必修缺陷就退回对应节点。

- 同一资产走生产渲染器输出整体、灰模、正侧背、头脸三视、胸/肢体局部、装备组合及完整转台。检查原生圆屏、低档拖动、极端俯仰、裁剪和缩小辨识度；放大结构图不算真机截图。
- 剔除差异定位到部件/面及触发视角，修几何、法线或确有需要的薄片双面属性。不能放宽已有阈值、全模型关闭剔除、按截图补洞。隐藏面必须真实补回再对照，内部像素/局部重画与轮廓边界误差分开记录。
- **钟形／外扩薄甲复核**：小腿、裙甲等带可见内唇的薄壳在侧后俯仰时可能同时露出内外两面。先用剔除差异定位到具体部件和触发角度；若确属有物理内外面的薄壳，只对该语义部件保留双面，并用固定角与连续旋转复测。禁止借此全模型关闭剔除或掩盖法线、封口错误。
- 回归实际可用姿态和相机范围、缓存身份、切换、重入和拖动；自动旋转/复位仅在产品合同保留时测试。共享控制器变更覆盖所有展品；未改资产可引用未失效结果并标明未重跑范围。
- 本项目当前每台一个完整装备展品，仅两侧切换按钮和手势拖动，松手保持角度，不提供 AUTO/RESET；无装备、头部等属于诊断视图，除非用户另有要求不加成浏览页面。“一个展品”不是锁死一个相机角度。
- 面数、缓存工作区、固件大小、检测用例数都按实际记录。RX-78 的 3284 面、710712 B 和每台 864 组是历史实现数据，不是任意模型的固定配额、相似度或 FPS。

### SD / G7：交付和反馈闭环

完成 G6 再执行已授权的构建/加载/烧录，核对目标设备、二进制哈希与启动，释放监视串口。没有烧录授权不把本流程当授权。保存用户原话、所指版本与认可范围；启动成功、FPS、用户外观认可分别记录。反馈落到最早受影响节点，补入模型卡和有复用价值的规则；新模型先读取这些规则再动手，不能让用户重复当检查员。

## SD 牛高达验证后的补充门禁（2026-09-14）

用户对已烧录的 SD BB387 反馈“牛高达做的很好”。这证明 RX-78 的方法已在第二款 SD 资产上完成从主动找错到用户认可的闭环，不证明无需审查就能适用于所有机体。旧 HG 牛高达 R2 未验收的历史结论仍保留，不能与 SD BB387 混淆。

- **G2/G5 重复附件单元**：炮阵、左右翼、推进器分别保留诊断面范围；同一 Part 下的不同单元也做两两相交检查，不能因语义标签相同而跳过。翼片展开方向、前后面、折叠背板轮廓均从说明书核对。相关单元角度或厚度变化后重跑。
- **G5 连接继承局部坐标**：附件改变朝向时，支架端点由双方局部挂点求得；不能保留旧世界坐标杆件，导致穿插、悬浮或端头露出。近景与完整前后视共同验证。
- **G5 负例**：保留受控装配偏移的自动负例；正确版本相交为零之外，还必须验证错误版本会失败。每款独立描述正常插接范围，不移植 BB387 的坐标白名单。
- **G6 回归证据**：除共享路径测试外，未修改的已接受资产源哈希与原生像素逐一比较；UI 字体、图标等明确变更单独记录。不能用“回归通过”取代不变项检查。

BB387 自检中实际拦截过头壳偏小、枪身穿臂、相邻炮片穿越和外露连接杆；其最终 864 组显示检查与用户认可分别记入 `docs/Gundam-Museum-SD-Nu-制作卡.md`。下一款仍须完成每个节点。

## SD 强袭执行中补齐的门禁（2026-09-14）

- **成对结构对称性**：胸口进气口、眼框、肩部凹口等设计上对称的零件，用同一局部定义镜像生成。正面相机 yaw/pitch=0 检查内外边缘的高度、斜率、宽厚与深度；增加镜像顶点误差断言及单侧抬高负例。不能把左右都向同一方向倾斜误认为对称，也不能用有方向光照的 RGB 完全相等代替几何检查。强袭首次只看斜视漏掉进气口错误，由用户指出；此项是流程缺口，已修复，不能记为此前自动门禁已拦截。
- **凹口与层叠甲片**：凹口深度沿该表面的法线，水平肩顶不能直接套前向 Z 深度。膝甲内嵌片、前臂面甲和胸口回折面需核对壳体前缘与背壁的距离；放大图和原生图都看，防止层间重叠条纹。剔除开关结果相等不代表没有 Z fighting。
- **拳壳也参加装配检查**：把腕轴与拳壳分开标记；只允许腕轴进入前臂，拳壳对前臂装甲必须零穿插。手的位置改变时，枪柄、步枪和腕轴端点整体跟随，重新检查离地与完整装备旋转。
- **返修后的证据**：用户指出几何缺陷后回到对应节点修复，重新渲染、测试和构建，旧图不能冒充修复后结果。正确记录主动自检与用户反馈各自发现的问题。

## 曲面占比高的机体：G1–G6 专项门禁（扎古／沙扎比两轮复查）

适用于圆顶头壳、鼓肩、鼓胸、钟形腿、环绕管线较多的机体。沿用分面光照和有限几何预算；本节约束形体与证据，不要求换引擎或把所有装甲磨圆。每款仍锁定自己的官方 SD 系列、骨架和装备构型。

1. **C01 先区分曲面类型与硬折边（G1/G2）。** 每个大件标明圆顶／椭圆鼓壳／外扩薄甲／圆管／平板及官方依据。沙扎比的头冠、肩顶折边与盾牌不能套扎古圆顶；单眼机体也不能共享一条平直黑眼罩。角饰颜色、弹鼓轴向和炮舱轮廓须直接看本款商品图，不从角色印象推断。
2. **C02 比例表含位置，不只含外包围盒（G2）。** 以不含角饰／装备的头盔顶到脚底 H 为共同分母，另记录头宽、肩宽、胸宽、腰高、露颈、髋膝踝与脚宽；照片区间和三维参数分列。对每个鼓壳再列底、下腹、最宽处、上腹、顶端的宽／前深／后深／中心偏移，注明最宽截面位置。两个形体外包围盒相同也可能一个是桶、一个是圆顶。
3. **C03 截面变化先于细分（G3）。** 先建立肩部鼓起、胸部前凸、头顶和下缘收口、小腿上鼓—中收—下摆外扩；正／两侧／背／两斜视共同核对。不能只给三截面圆柱增加圆周段数。连续鼓面允许可见分面，但不能出现无参考的水平台阶、球形鼓包或方盒轮廓；真实硬折线保留。
4. **C04 分色与主体共用边界（G4/G5）。** 鞋底、鞋甲、曲面眼窗和贴合胸甲按相同截面或共享边界分区；需要独立壳时给出明确的前后间距和回接。禁止用穿过圆壳的平板涂色。沿全部可见方位看是否出现三角异色、锯齿或背景洞；剔除开关一致不能证明没有相交。
5. **C05 管路连续与环节辨识分开（G4/G5）。** 管路先定义从接口到接口的中心线，控制前／侧／后转弯与半径；沿路径共享截面环，检查切线、弯曲外侧间隙和内侧穿插，再加可辨的节环。每个短管封盖叠在转弯处会形成凸结和暗缝；不能用四根粗直棒代替绕头软管。采样曲线须检查过冲与零切线，竖直段须使用稳定备用基向量。
6. **C06 关节与装备遵守曲壳的真实接口（G5）。** 改肩／前臂／拳体积后，复验腕轴长度、拳壳位置、枪柄共轴和肩盾支架。为取得零相交而把手向前挪出一根长杆是失败。正常插接白名单应落在具体枪柄面范围、实际拳部或小型连接件；不可整类豁免 Hands／Shoulders／Waist。弹鼓先查轴向，炮舱先查容器与安装，再查内部数量；可见数量正确不代表结构正确。
7. **C07 以原生投影分配面数（G5/G6）。** 保留主轮廓转折与必要开口，细分集中在头顶、肩弧、胸腹和外扩下摆；减少不可辨的周向段／内盖／重复环节，不改变总容量来迁就建模。圆弧可用投影弦误差估算细分（半径 r、整圆 n 段时最大弦差 r×(1−cos(π/n))），最终仍看100%与65%原生图及旋转；几何平滑度、分面明暗和颜色正确分别判断。
8. **C08 增加能失败的形体门禁（G6）。** 用实际三角面与多高度平面的交线测头壳／甲壳截面；保留“中段压瘪而整体包围盒基本不变”的负例，验证仅看头身比漏掉的问题。测试支持局部尺寸与曲率关系，不自动证明像官方模型。面片总数、文件数量和零像素回归均不是美术评分。
9. **C09 两轮必须有独立发现与最终重看（CR1/CR2）。** CR1 对官方多视图检查比例、截面、辨识点和连接，逐项修正并留同相机证据；CR2 从最终原生图、65%拖动图、48方位转台、正侧背及过滤局部图重新找错。二轮发现须回到相应节点，受影响图与测试重做。各模型独立记录“发现→依据→修改→复验”；没有新问题也列实际核对的部位与视角，禁止复制上一轮通过结论。
10. **C10 可见支撑必须形成连续实体链（G2/G5/G6）。** 对头、面罩、武器、背包、腰挂件和悬臂附件，制作卡明确写出“父件 → 安装件 → 子件”；每一段都要有实体几何并在双方接口处重叠或插接，不能用背景黑缝、阴影、颜色相邻、投影单点接触或零相交结果冒充连接。记录安装件独立面范围与两端包络，保留把安装件或子件平移到断开的受控负例；正常版本通过和错误版本会失败必须同时成立。证据至少包含父件与子件同时可见的装配近景、完整正／侧／背、65%图和全方位转台；孤立过滤图只能说明子件自身，不证明装配。修改父件体积、子件姿态或局部／世界变换后，重新求双方挂点并重跑。2026-09-15 真机反馈检出的扎古头／热能斧及沙扎比头／面具悬空，作为本规则的固定反例。

本轮额外反例：贴花／接缝要明确局部坐标与世界坐标，防止原点偏移重复相加形成悬空细条；叉槽必须从正侧背均成立，不能只画黑线。若剔除A/B出现内部差异，先定位具体面，逐个验证；沙扎比仅保留两处喷口封底双面即恢复通过，给整个胸或全机双面没有依据。三角面使用 `face(A,B,C,C)`，不要把A错误填入第四点导致重复顶点路径产生缺片。遵循既有面数容量与优化回归，但不能据此承诺真机FPS不变。

本轮实例与局限见仓库 `docs/Gundam-Museum-曲面机体两轮自检-20260915.md`。此门禁适用于后续曲面机体；具体截面坐标、环节数、武器角度不作为通用参数。

## 展示尺寸与交互变更的补充门禁（极简界面复盘）

模型没改不代表显示结果没变。更改相机尺度、分辨率、视口或 UI 时，从 G6 重入，保留模型源哈希并对所有受影响展品重新检查。

- **先确认实际有模型**：内部缓冲、活动光栅、输出 blit 的尺寸约束必须一起核对。极简界面首次用384缓冲输出424时，blit拒绝绘制；因此须检查足够的模型像素、不同机体画面确实不同，不能只靠剔除差异为0判断成功。
- **圆屏与矩形边界分别检查**：模型处于圆屏内，仍可能被内部绘制矩形截断。全装备、整个允许俯仰及方位、最高/最低显示档逐项检查；包括最长的炮阵、天线、步枪与背翼。牛高达在初始放大尺度下触碰视口边缘，改为固定留白后再验收，不能随旋转自动缩放掩盖问题。
- **分辨率变化重测薄片覆盖**：新采样位置会暴露旧尺寸下不出现的缺口。定位到触发相机与具体部件/面，按薄片结构保留必要双面，再比较完整参考、内部像素和轮廓边界；全局放宽剔除角度无效时不能继续盲调。此次 Nu 背包安装边缘采用部件双面保留，三个模型几何未改。
- **移除控件也移除动作与热区**：绘制和触摸共用边界。删除 AUTO/RESET 时取消旧位置的点击动作及定时旋转，验证拖动经过按钮、滑出取消、松手保持角度和慢帧完整手势只消费一次。复用其他 App 输入时采用独立上下文并回归原界面；退出通道、失效取消和重入释放门禁仍保留。
- **局部刷新和预算跟随新视口**：直接显示与 Canvas 两条路径同步修改脏区域；从旧角度/旧机体切换后比较局部刷新与整帧，不只重画同一张静态图。记录缓冲增量、生命周期和目标构建余量；提高内部像素数不等于已证实真机 FPS。

本次具体实现、2592组主机检查与未测真机项见 `docs/Gundam-Museum-极简展示界面.md`。这些是通用检查规则，424像素、各款放大倍率和内存值仅是当前项目数据，不硬编码成后续模型的配额。

## G0 · 锁定目标与验收范围

- **输入**：用户指定的对象、展示用途、项目现状。
- **制作**：记录准确版本／构型／涂装、设备与相机范围、可见附件、可编辑格式、面数和内存等预算。区分忠实复现与用户要求的风格化。只有泛称时先检索版本并记录选择依据；差异会影响预期且无法推断时再澄清。
- **产物**：制作卡的目标合同，修改前的生产基线。
- **检查／门槛**：能明确回答“做哪一款、从哪些角度看、在哪个屏幕上看、哪些特征不能丢”。不要使用“像高达”“精细一些”作为唯一通过条件。
- **失败去向**：留在 G0；关键目标不明确时不投入精修。

**落实 RX-78 R1 的教训**：把技术样机与目标质量分开记录。本仓库后续高达以用户已接受的 RX-78 R5 作为最低打磨程度参考，同时以本款官方／实物参考判断形状；不能以“渲染链路能跑”或“能认出角色”作为完成标准。列出不能以预算为由省略的轮廓、分色和连接，以及确实可简化的微小细节。

## G1 · 建立参考覆盖

**SD 改造及站姿补充（2026-09-14 用户反馈）**：HG 与 SD 属于不同的比例合同，转换时重新选择同款套件并建立头身、肩头、短肢及大脚锚点，不能压短旧身体后沿用旧头脸。用户指定站姿时，将参考中的足底接地、髋膝踝、肩肘腕和武器锚点写入 G2/G3；用关节刚体旋转，检查持物随手和双脚共面。G4 必查眉檐与面罩前缘的实际深度及颊框到后壳的连续性，不能改取景掩盖凸脸。天线尖锐程度以最新用户基线为准：要求尖端时宽厚同收束；指定玩具钝尖时保留小幅圆钝端面，不能强制单顶点。正斜侧及原生低档共同复验，避免方棒或过度针尖。每步完成后记录实际自检，再进入下一步；修改影响的旧检查必须重跑。

- **输入**：G0 的确切版本及展示范围。
- **制作**：实际打开同版本成品多视角；补充说明书、爆炸图、板件／拆件图和关键部位近照。账本标注来源、版本、视角、用途、可信度及未知项。成品图判断组装外观，板件解释分件和连接，特写判断比例与深度。
- **产物**：参考账本、按部位组织的参考索引、覆盖缺口。
- **检查／门槛**：整体正面、侧面、背面及关键辨识部位有可用依据；展示能看到的顶部、底部也纳入。至少用另一角度或另一独立来源交叉检查高风险结论。多张转载同一照片不算独立证据。
- **失败去向**：补参考；找不到的部分明确标为估计。关键辨识点依据不足时保持待证据，不能靠熟悉该角色的印象蒙混通过。

不要把“官方大部分图片”当投票：先剔除不同版本、改装和不适合量比例的插画。未涂装照片可用于结构，但不能替代官方配色依据。没有板件的对象可用维修图、截面图或同版本多角度照片，不编造板件关系。

**将 RX-78 R3–R5 的补图提前到建模前**：

1. 成品参考覆盖中性全身与能露出遮挡结构的其他角度／动作；不能只看持盾正面。找出至少两张主参考之外的可用成品图交叉检查，同一照片的转载不重复计数。
2. 高达头脸须有足够清晰的正面、侧前方及侧面依据；全身图里几像素的脸不能作为局部比例依据。官方近照不足时补同版本实物近照，并明确其来源与涂装差别。
3. 板件／拆件／说明书在 G2 前查看。逐项说明哪张图支持外形、哪张解释装配、哪张支持配色。特殊涂装版只能辅助核对已确认相符的结构，不据此混合版本。
4. 为每个关键结论留下另一角度或来源的核对结果；“下载了很多图”不能代替读图结论。缺少关键依据时继续找资料，不进入凭印象精修。

## G2 · 拆结构、定比例和可见范围

- **输入**：参考及项目预算。
- **制作**：按壳体、连接件、附件拆成独立部件；记录部件编号依据、装配层次、真实空隙与支撑。建立整体和局部的比例锚点，记录分母与测量依据，例如头宽归一化的面罩宽、眼跨度、下巴宽。
- **产物**：部件清单、比例锚点、需要保留的空区、可省略内部件清单及理由。
- **检查／门槛**：分件后可以解释正侧背外观和连接关系；相互矛盾的编号已核对。制造用浇道、封闭内部筋不自动进入游戏网格；会从关节缝、低角度或拆卸状态露出的结构必须保留。
- **失败去向**：结构依据冲突回 G1；预算不可承受回 G0 调整方案。

**落实 RX-78 R4 和牛高达侧甲误读的教训**：

- 每个高风险部件完成“成品上位置 → 拆件轮廓／说明书编号 → 代码部件”的对应。通过正、侧、背确认它在前方还是侧方，以及和哪个关节连接；不能根据一张正斜照片给深色色块命名后直接建模。
- 高达整体记录：头身关系、肩宽／腰宽、胸腹长度、腰线与裙甲下缘、髋／膝／踝高度、上下肢长度、脚长、主要装备包络。局部记录：以本款头壳宽归一化的面罩宽高、眼跨度、下巴宽高、天线跨度；分别注明估计依据与不确定性。
- 列出必须真实存在的空区与内壁，例如眉檐下眼窝、颊框内的面罩、肩下轴、踝甲与鞋面、喷口和浮游炮单元间隙。制造内部件可省略，外观必需的空区与支撑不可省略。

## G3 · 灰模轮廓门禁（CR1 前半）

- **输入**：结构计划、比例锚点。
- **制作**：先做主要体块和连接，使用中性灰；固定正、侧、背、两侧斜视和必要俯仰相机，保存基线。先改截面和位置，再增加细分。
- **产物**：灰模多视角、比例检查记录、偏差清单。
- **检查／门槛**：逐项检查长宽高、主要部件相对尺寸、轮廓转折、空区和附件包络。模型自己的基线与新版保持同相机；与照片比较只做有记录的等比配准，不能拉宽压扁图片来“对齐”。照片透视估计不写成实测尺寸。
- **失败去向**：轮廓错误留在 G3；部件理解错误回 G2。明显体块偏差未解决前，不进入刻线和装饰精修。

**落实 RX-78 R2/R3 和牛高达胸腰、腿部返工**：先无装备检查身体，再装回装备检查包络和遮挡。按 G2 的整体锚点逐项记录参考估计、当前值和偏差方向。检查肩甲上下收口、胸壳向前突出与收腰、独立裙甲长度、小腿上鼓／中收／踝部外张、鞋面与鞋头关系；不以统一盒体或圆柱加细分替代这些转折。参考照片与模型的相机／姿态不同，先识别透视影响再改尺寸。修改后保存同相机旧／新灰模，并重新检查正、侧、背和两侧斜视。

## G4 · 关键辨识点门禁（CR1 后半）

- **输入**：整体通过的灰模、关键部位近照。
- **制作**：按“对身份影响 × 当前不确定性”排序检查部位。高达通常先头脸，车辆可能先车头／座舱／尾翼。隔离部件、去掉无关身体倾斜，生成正面、斜面、侧面特写；必要时加入身份相关色块。
- **产物**：参考／旧版／新版对照，比例锚点修正和三维前后关系记录。
- **检查／门槛**：关键轮廓、局部宽高和层次均有依据；正面变好后侧面不能恶化，特写变好后还要回看全身。不能以其他部位通过来抵消脸部仍明显不像。
- **失败去向**：比例或深度错误留在 G4；近照不足回 G1；牵动整体比例回 G3。先解决形体，不靠增加槽线掩盖。

**直接执行 RX-78 R5 的头脸校准闭环**：

1. 隔离 Head，去掉身体倾斜，固定正、侧前方、侧面相机；改动前保留基线。参考只做记录过的裁剪、等比缩放与平移，尽量接近视角，不拉伸图片凑比例。
2. 先校准头壳与额冠，再核对面罩、眼跨度、下巴、天线的归一化宽高。每次说明改动解决哪个可见偏差；不能直接复制 RX-78 R5 的百分比给另一款头脸。
3. 单独核对前后层次：眉檐、眼窝、眼间区域、鼻梁／面罩、下巴、颊框和后头壳。检查是否有凸出的整块眼罩、过低眉心、侧面面罩比眉檐更靠前、颊框脱离后壳等实际返工过的问题。
4. 形成参考／旧版／新版对照，实际看三种局部视角，再回看全身与原生特写。正面改善但侧面更差、靠扩大眼睛提升小图辨识度却破坏特写，都需继续修正。
5. 宽度落入估计区间只通过该项尺寸检查；头壳曲率、侧轮廓和深度仍明显不像时，本节点仍为返工。不得用增加口槽、标记或全身细节抵消脸部问题。

**SD v2 退回补充**：正面头宽高不代表侧面体积通过。单独核对后脑最大截面的位置、头顶与下缘收口、颊框到后壳的连续曲率，并保存同相机侧面对照。天线不能只检查总跨度和端点：至少检查根部、中段、外段的截面宽度与厚度，正、斜、侧面同时确认渐缩关系。指定玩具钝尖时保留小端面，但不能据此把整支天线做成等宽等厚细条。

## G5 · 精修、材质与可见面优化

- **输入**：已通过的形体与辨识点，板件和材质依据。
- **制作**：补倒角、壳厚、接缝、真实凹槽、连接轴和分色／贴图；按屏幕贡献分配预算。贯通孔、轮廓缺口、可见腔壁由几何形成；不影响轮廓和深度的表面纹样可由材质表达。
- **产物**：可编辑精修资产、材质卡、优化前后版本、CR1 修复记录。
- **检查／门槛**：部件既不悬浮也不穿透，凹槽没有被旧封口堵住，共面或过近表面不闪烁；灰模和关键特写仍成立。每次删“看不见的面”，用补回版本作对照，覆盖约定视角、姿态、附件状态和各档；出现差异先查并恢复误删，不能放宽阈值掩盖。采样零差异只覆盖已测范围。
- **失败去向**：结构错误回 G2–G4；材质／优化问题留在 G5。新增姿态或可拆件会使之前的隐藏面结论失效，必须重新检查。

**直接执行 RX-78 R4 与牛高达 R2 的结构复验**：

- 平整的肩盖、裙甲和前臂盖先校共面，倒角带与侧壁独立生成。非共面多边形的三角扇若产生参考中没有的鼓包，重做面，不靠材质或加面数掩盖。
- 曲面依真实截面变化重建；头壳、颊框或小腿在关键视角仍呈明显错误的方盒轮廓时继续精修。低模预算允许可见分面，不允许主轮廓错误。
- 开槽须替换原封闭表面，并检查后壳、相邻壳或旧盖是否再次封住凹槽。放大看边框、凹面和内壁的连续性；不能仅把外贴条改名为通风口。
- 炮口／喷口缩短后同时调整凹腔深度，确认凹底留在外壳内。开放踝甲／头壳后重新检查内壁上缘、底部和反面可见性，不沿用封闭盒体的剔除假设。
- 分色片跨越胸壳折线时按折线分段贴合；检查近共面相交、锯齿和闪烁。鞋面、鞋头、鞋底分别对应参考中的边界，不通过把整只脚涂成单色消除穿插。
- 隐藏面省略必须有实际补回面和多视角对照。补回配置没有新增几何时，即使像素相同也不能声称实现了删面优化。出现差异恢复误删或修复结构，不提高门限。

## G6 · 生产显示与技术回归（CR2）

- **输入**：精修资产及生产渲染通路。
- **制作**：从同一生产资产输出原生尺寸画面、结构特写、转台或相机过渡；验证真实使用场景、低档、缩放、装备切换、输入与重入。记录几何、内存、产物大小和实际执行的测试范围。
- **产物**：生产画面、证据 manifest／report、测试日志、源版本及构建记录。
- **检查／门槛**：实际打开看图，确认身份、裁剪、缩小辨识度、遮挡和闪烁；几何／容量、相关回归、构建／导出通过。共享代码修改检查所有受影响资产；仅局部资产修改可复用未失效的历史结果，但标明版本和未重跑范围。
- **失败去向**：屏幕可读性问题回 G4／G5；渲染和交互缺陷留在 G6。截图齐全不等于模型像，主机高分辨率图不等于真机截图，测试组合数不等于审美评分。

**落实两次模型返工中的显示检查**：技术日志与视觉结论分别记录。先实际查看最终原帧及对照，再写结论；不能引用上一轮源码的截图。建模中发现并修复过的问题要在最终对应视角再查一次。结构大图、原生展示图和巡展均由同一最终生产资产生成；不得靠临时修改取景、修图或另建更好看的模型掩盖缺陷。

**旋转性能回归（SD 展示复盘）**：先复用项目已有的按需刷新、独立输入、帧事务、共享顶点缓存和材质专用路径，再评估降画质。新增模型、放大展示或更换光栅算法后，在相同模型、尺寸、角度、内部采样比例下保留优化开关做 A/B；除规则转台外，加入固定种子的连续随机角度与俯仰限位，核对完整 framebuffer、薄片边缘和深度遮挡。四驱车中通过的增量插值不能直接认定适用于更大的 SD 光栅：本次固定角度通过后仍在连续角度发现差异，已排除该方案。缓存需覆盖模型／装备／材质／姿态失效、满容量与近裁剪回退；记录常驻和临时内存，禁止逐帧建索引。几何计算减少量、主机耗时、真机 draw/present/FPS 分开记录，没有设备 A/B 就不宣布流畅度验收完成。

## 交付前视觉复核 · G6 到 G7 的必要条件

**同系列机体的身份分色审计（SDEX 命运返修）**：外观反馈涉及配色或“像另一台”时，先用实际看过的同款成品建立小型 `部件 → 数量/轮廓 → 主色/内色 → 参考图` 表，逐项与代码和最终图互核。重点覆盖天线、眼框、胸口内口、肩膝、盾与翼的正反面、背挂武器。官方涂装图决定分色；同款未涂装/贴纸模型可解释装配，不能把塑料原色当最终色。不要把另一款常见的白黄四叉、黄胸口、蓝膝等习惯套入新机体。能可靠自动化的身份不变量可加局部材质/数量测试，但仍需实际看图。被用户指出读图错误后，旧卡的相应“视觉通过”须明确撤回，不能继续当参考事实。

原生低档证据须包含**完整装备的 65% 拖动帧**；无装备低档只覆盖机身，不能代表翼、盾和长武器。开口头壳还须检查正侧视的面框→回接壁→后壳连续性，颈柱接触通过不代表脸框已连接。

清空上一轮的“通过”判断，从最终图片重新检查下列项目，并在模型卡填写证据与结论。检查在当前任务内自主执行，不必等用户逐项批准。

1. **版本与装配**：同版本参考对应正确，前／侧／背部件位置、主要分色、连接和开口成立。
2. **整体**：无装备灰模与完整装备均核对过；头身、肩腰、胸腹、裙甲、四肢、脚和附件轮廓没有尚待修复的明显偏差。
3. **关键部位**：参考／旧／新正斜侧对照已看；比例与深度同时成立，未将已知方硬或失真的关键轮廓仅写进“局限”后放行。
4. **几何表面**：没有未解决的错误鼓包、悬空、穿插、被封凹槽、缺少可见内壁或深度闪烁。
5. **生产显示**：原生整体、局部特写、旋转和低档均核对；最终证据与最终源码一致，相关技术检查通过。
6. **遗留项**：逐项写明部位、视角、影响与处理。影响主轮廓、辨识点、装配或约定展示体验的项必须返工；只有合同允许的微小刻线、不可辨印字等简化可保留。参考缺失不是简化授权。

任一项不满足，回到对应节点继续制作，不以“先给用户看看”“基本完成”“候选版”规避。当前条件确实无法解决时说明具体缺口和所需信息，不宣布模型制作完成。用户主动要求中间版本时可展示，但明确它是尚未通过门禁的过程产物。

## G7 · 目标环境与用户验收

- **输入**：可交付候选版、已有部署／烧录授权。
- **制作**：在目标环境加载明确版本，核对实际产物哈希和启动；提供整体与关键部位查看方式。保存用户原话、日期、资产版本、实际构建标识和认可范围。
- **产物**：交付清单、部署记录（适用时）、用户视觉验收记录、仍待验证项。
- **检查／门槛**：技术运行通过与用户外观认可分别记录。没有目标硬件时只交付软件候选版；没有测 FPS 就不能写性能验收通过。只有明确用户反馈才把相应范围标为用户已验收。
- **失败去向**：把用户反馈落到具体部位和视角，回到最早受影响节点；不从头重做，也不直接宣布“下一版肯定像”。
