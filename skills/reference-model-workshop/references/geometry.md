# 结构：先纠正形体，再提高精度

## 参考与尺度

锁定官方名称、商品编号、版本、底盘／构型。先看同版本成品多视角，再用裸壳或零件图解释接缝、厚度与支撑。不同改装、压铸版、特殊涂装的结构不能直接拼成一辆“官方车”。真正打开参考图；文字摘要不足以建模。

在模型卡分别记录：已公布实测尺寸、从照片估计的比例、看不到的未知项。透视图里的长度比不是测量值。先约定原点、单位、朝前／上／左右、镜像与导出变换，禁止在输入或物理层翻转控制来补视觉坐标错误。

## 从大到小的建模顺序

完整新模型按 `pipeline.md` 的 G3／G4 先过整体与关键辨识点门禁；下列部件配方用于实现，不意味着要等所有次级细节完成后才检查身份特征。

1. **剪影和比例**：轴距、轮距、前后悬、鼻宽、座舱长高、尾部高度；飞机对应翼展、翼根／翼尖、机身长细比和尾翼位置。用无纹样灰模验证。
2. **关键折线**：最宽肩部在哪个纵向截面、何处开始收腰、座舱下缘是否吞掉通道。截面按真实折脊和变化点布置，不能用统一圆壳加细分替代。
3. **部件与负空间**：中央壳、轮罩、翼、支架、管路分开；列出必须贯通的通道、翼缝、轮拱和支撑间隙。开槽后检查背面有无另一面封回去。
4. **厚度与曲面**：硬风挡不是气泡；轮罩薄唇不是延伸进轮胎的实心墙；金属管是圆截面，必要时分段弯曲，而非长方体。
5. **附件与辨识点**：轮盖／轮辐数、导轮层数与位置、灯窗、进气口、发动机鳍片；以参考决定，不拿统一附件替代所有版本。
6. **涂装**：结构成立后再加 UV、色块、文字。后续材质发现结构错误时退回结构修复，不涂黑遮掩。

## 可复用部件配方

| 配方 | 输入／输出 | 关键检查 |
| --- | --- | --- |
| 折脊壳体 | 纵向截面：宽度、侧裙、边缘、顶高 → 分段曲面 | 保留肩／腰拐点；端盖不封住设计通道 |
| 独立薄轮罩 | 内／外缘、冠高、薄唇 → 单侧开放壳 | 内外沿连续；镜像几何与 UV 对应；不穿胎 |
| 管体 | 路径、半径、分段 → 圆截面管 | 轴向基向量稳定；端部进入附件，无悬空穿透 |
| 凹入进气口 | 外唇、内唇、隧道内壁、后盖 → 有深度口腔 | 后盖退后；侧口沿开口法线测深，不套车头方向探针 |
| 开槽翼／支架 | 独立翼梁、端板、支撑与空区 | 不用透明／黑纹模拟真空区；背面也能透视 |
| 轮胎／轮毂／导轮 | 固定包络 + 按版本轮盖或轮辐 | 内侧闭合；只标记需要转动的部件；不会带壳旋转 |

这些是结构配方，不是必须使用同一数据格式的通用组件。项目已有成熟 mesh/DCC 工具时用其实现；StopWatch 的实际 C++ 部件模块见项目适配。

## LOD 与几何检查

从同源结构生成各档位。先减圆周／隐藏面细分，再减次级装饰；宽肩窄腰、特征尾翼、开口、主要灯窗不能被删成通用小车。依据屏幕占比设预算，不把高档面数当目标。

将关键辨识点转成可解释断言：肩宽大于腰宽、指定通道无高面、进气口唇比后盖突出、特征支撑存在、轮辐数正确。检查所有档位；测试采样点应位于各档共同有效区域，不能放宽穿透容差掩盖错误。

另查有限坐标、输出溢出、部件语义、镜像、包围盒、轮胎或运动部件包络。采样检查只证明采样点无问题；必要时在 DCC/引擎使用三角形相交或解析检测。三角面可以用退化四边形表示，别把合法表示方式误判为坏网格。

## SD RX-78 身体与装备返修的继承项

用户补图可能仅用于指出问题。先记录其用途，不能自动把它提升为尺寸、版本或姿态基线；原有比例图与同构型官方资料继续生效。胸、肩、前臂的正面宽高和侧面厚度分别检查，胸甲使用随高度变化的截面与凸出的中央胸块，不能通过放大头身整体或改相机补偿。

握孔、枪柄共用装配坐标；枪身仍需避开前臂。盾板、背部支架和前臂插接点分别定位，保留可见的支架与间隙，禁止只把枪盾向外挪成悬浮件。完整装备态必须检查附件与所有其他部件的三角面相交，并保留握持及盾背组合近景。实际插接允许的交叠只能限定在明确的小范围接口内，不能豁免整对部件。用已知穿模旧版验证检测确实会失败；注明共面接触、完全包含等未覆盖情况，再由多视角审查补查。
