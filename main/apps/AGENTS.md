# App 外设输入接入约定

新增或修改支持 Joystick2、Dual Button 或类似外设的 App，以及维护 Launcher 的外设导航时，先阅读仓库根目录的 [外设输入接入与故障排查规范](../../docs/外设输入接入与故障排查规范.md)。该文档是跨 App 输入接入的统一入口。

- 按完整生命周期核对供电、时钟、任务、校准、输入消费和关闭，不只复用驱动构造代码。
- GPIO 按键采样与菜单方向检测不能依赖渲染，也不能等待 I²C/RGB 操作；连续量和离散事件分别处理。
- 保留失联中性控制与返回/退出，清理切页和重入的旧事件。
- 按文档验证慢帧、总线超时、校准、故障恢复及跨 App 重入。区分主机测试、目标构建、真机验收，未验证项不得写成完成。
- 结合规范开头的实施更新和 R26 记录区分已实现、主机验证、真机验证及待办，不能把当前 Provider 当作全部验收完成的范本复制。修改共享驱动时同时检查 Racer、Vector Run 和 Launcher。
