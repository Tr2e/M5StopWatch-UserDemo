# StopWatch 长臂小钩式科技横梁背夹 V6

## 固定方式

V6 不使用磁铁。实物打印已确认圆形薄背片尺寸正确，因此圆片、横梁、开窗和周向钩位保持 V5 不变，只修正卡钩轴向长度：

- 正式版单个钩臂深入 `16.40 mm`，宽 `5.50 mm`，外壁厚 `1.25 mm`。
- 钩体位于成品方向 `70°/110°/250°/290°`；官方 STL 已按完整 `5.5 mm` 钩宽和全臂深扫描，避开侧键与壳体凸起。
- 四钩分布在上、下两侧但偏离正中位置，顶部/底部正中的接口区和左右按键区均为空。
- 名义机身厚度 `15.50 mm`；1.0 mm 厚的钩趾覆盖深度 `15.40–16.40 mm`，跨过前壳边缘。
- 钩趾内缘半径 `25.14 mm`，径向预紧维持 `0.35 mm`。
- 钩趾从外壁向内有效伸入约 `1.0 mm`，落在前壳收窄肩部，而不是后壳直壁。
- 钩体停在前壳肩部，不压住屏幕可视面。
- 拆卸时先从一个下侧钩向外轻拨，再依次释放其余三个钩，禁止直接拉扯科技框。

V3 的 `3.20 mm` 短钩没有到达肩位；V4 修正长度但钩宽擦到凸起；V5 已让开凸起，但 `13.80 mm` 实物仍未跨住前缘。三版均已归档。

## 科技横梁

- 底部一体横梁：`44.00 × 8.00 × 7.80 mm`。
- 两孔中心距：`32.00 mm`，即标准科技梁 `8.00 mm` 网格的四个节距。
- 默认打印孔径：`4.90 mm`。
- 两孔对准照片中灰色 5×7 框顶部箭头所指的两个角孔。
- 使用两根标准摩擦销连接背夹横梁和灰色框。

## 后背开孔

- 左右排母：两个 `6.40 × 19.20 mm` 圆角贯通窗。
- GPIO3/GPIO4 的 1×2 杜邦头可以在背夹安装状态下插拔。
- 扬声器：`13.00 × 9.20 mm` 独立开窗。
- Joystick2 的 Grove 线保持从 PORT.A 侧向引出。
- Dual Button 信号线从排母窗进入灰色框中央，再在框侧做扎带应力释放。

## 打印和试装

1. 已提供 `output_v6/rear_hook_fit_15p2mm_v6.stl`、`15p8mm`、`16p4mm` 三档试片供公差复核。
2. 正式主件按实物反馈默认采用 `16.40 mm`。
3. 如果径向太紧，将 `HOOK_TOE_INTERFERENCE` 从 `0.35` 调到 `0.20–0.25`；太松则调到 `0.40–0.45`。
4. 打印 `output_v6/technic_pin_hole_coupon_v6.stl`，用实际摩擦销选择 4.80、4.90 或 5.00 mm。
5. 主件建议使用 PETG，层高 `0.20 mm`、4 道墙、30% 填充。卡钩区域禁止使用脆性 PLA 反复拆装。
6. 由于横梁与卡钩分处背片两面，切片时建议让横梁长边落在热床，并仅对背片下方使用树状支撑；不要在卡钩内侧生成难以清理的支撑。
7. 先空载安装背夹并完成 20 次拆装，再连接灰色科技框和外设。

## 生成

```sh
python3 -m pip install trimesh manifold3d
python3 hardware/stopwatch_technic_back_clip/generate_back_clip.py
```

推荐打印文件位于 `hardware/stopwatch_technic_back_clip/output_v6/`。V1–V5 已归档，均不应打印。

## 实物门禁

官方 STL 能确定名义外壳轮廓，但卡扣手感取决于外壳批次、材料收缩和喷嘴尺寸。主件打印前必须先做卡钩试片；如果小钩会刮伤壳体、需要明显暴力才能扣入，或轻晃就脱落，应调整预紧量后重新生成，不能直接使用。
