## H2 实现边界

- 不创建虚假的速度矢量、垂直速度、导航模式、武器或能量数据。
- 不因第一人称模式复制第二套 HUD；共用相同语义，仅按相机模式控制机体基准和视角标签。
- HUD 只读取 `FlightState`、`CollisionStatus`、`InputStatus` 和当前航道标架，不访问 HAL、GPIO、IMU 或 I2C。
- Boost 速度增量只保留一个模型常量，模拟推进与 HUD 读数不得各自散落魔法数。
