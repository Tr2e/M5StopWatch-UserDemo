# SDCS 夏亚专用扎古 II 板件重做

日期：2026-09-16。范围只覆盖 Gundam Museum 的夏亚专用扎古 II，不改 RX-78、ν、强袭、命运、沙扎比。

用户反馈后期几台建模不满意，要求先从扎古开始。此前扎古主要按官方成品照片搭外形，没有按说明书分件对齐，所以看起来“像扎古”但结构不对。本轮按 **SDCS #14 MS-06S 夏亚专用扎古 II**（商品号 4573102588623 / 5058862）重做壳体。只用 SD 骨架；说明书里另售 CS 骨架步骤不进入展品。

## 旧模型哪里不对

对照官方成品、说明书和拆件，上一版生产网格的主要偏差：

1. **右肩盾**：官方 B2-13 是厚圆角盾甲，本身就是右肩甲。旧模型是薄平板，用长杆挂在手臂外侧。
2. **胸口**：官方是灰内架 + 深红胸甲包住中央黑块 + 粉领。旧模型是一块竖黑方，两侧贴薄粉片。
3. **裙甲**：官方 B1-3/4 是独立深红厚壳，罩住大腿。旧模型是腰上的薄粉翻片。
4. **腿脚**：官方是灰髋、粉大腿、钟形小腿、独立黑靴。旧模型从小腿一路扩成扁圆饼脚。
5. **机枪**：官方有机匣、侧面十字弹鼓、枪管、准星。旧模型是黑香肠顶一个圆盘。
6. **其余身份件**：左刺肩缺正面圆凸台；天线偏细长；背包太小；热能斧几乎看不见。

这些不是微调参数能过的，要从板件对应重做壳体。

| 胸：A1 内架、B1-2 深红胸甲、C3 黑胸、C4 背包 | 深红胸甲包住前方黑胸块，粉领，更大的双喷口背包。黑胸坐在胸甲前面，不嵌进壳体内部。 |

## 门禁改动

语义门禁保留：裙甲象限、腕轴插入、肩/盾/枪两端接触、短颈、头身间隙、机枪/斧/盾负例。

为新结构改了三处：

- 天线冠顶从 `3.15–3.19` 放到 `3.00–3.12`，对应缩短的刃天线。
- 右肩盾增加“不是挂在身后的薄板”的包络判断；盾甲作为肩甲，允许和上臂壳体在关节处擦边，对躯干仍要求非预期相交为 0。
- 大腿和靴子用双面壳体，避免从下往上看时单面底盖被剔除，和生产光栅器的背面剔除路径对不上。

## 自检仍看到的差距

对照官方成品，本轮软件图上仍然偏硬：

- 右肩盾是厚直角板，套件顶底有圆角。
- 中央黑胸是矩形块，套件更圆。
- 上臂灰骨架仍偏长，套件粉甲覆盖更多。
- 小腿与靴口有一条接缝；裙甲中央有左右分片缝。

这些不挡本轮“按板件重做身份结构”的目标，留给用户看真机后再决定要不要继续修。
