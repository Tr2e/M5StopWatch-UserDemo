# Vector Canyon Fighter：G3 实施记录

## 切片 G3.1：静态可运行场景

**范围**：应用壳、低预算峡谷线框与第三人称战机静态构图。此切片刻意不接入飞行物理、IMU、Joystick2 或 Dual Button。

### 交付物

- `AppVectorCanyonFighter`：可从应用列表打开和返回主页的独立应用。
- `vector_canyon_renderer`：以现有 `HAL` canvas 绘制黑底峡谷。
- 8 个深度环的线框峡谷：符合 Low 图形预算的起步配置。
- 原创、后方追视的线框战机：位于画面下部中间，宽约 62 px，明显小于圆屏直径的 18%。
- 克制 HUD：仅显示名称、速度、巡航与 IMU 就绪状态；未加入扫描线、随机标签或装饰性赛博元素。

### 设计校准审查

| 检查项 | 结论 | 证据 |
| --- | --- | --- |
| 视角是第三人称而非第一人称 | 通过 | 战机始终画在下部前景，峡谷向远处收束。 |
| 战机比例不过大 | 通过 | 机体宽约 62 px；466 px 圆屏中约占 13%。 |
| 峡谷承担穿梭感主体 | 通过 | 两侧岩壁、地面与深度连接线共同构成可读空间，战机未遮挡主体。 |
| 视觉遵守线框复古未来感 | 通过 | 黑底、低亮度绿青峡谷、浅色机体；无照片式渲染或随机装饰。 |
| 尚未偏离输入抽象目标 | 通过 | 此切片不读取任何控制器，避免在 `FlightInput` 设计冻结前写死输入方案。 |
| 实时预算有起点 | 通过 | 33 ms 帧间隔（约 30 FPS）和 8 个深度环，符合 G2 的 Low 起步预算。 |

### 构建验证

- 新增的两个 C++ 源文件已进入 ESP-IDF 的编译数据库并生成对象文件。
- `make -C build -j14` 成功生成 `build/StopWatch-UserDemo.bin`。
- 应用二进制为 `0x460680`，最小 app 分区 `0x4f0000`，余量 `0x8f980`（约 11%）。
- 已执行 `git diff --check`，无空白错误。
