# Vector Canyon Fighter：G4-H4 外围飞行仪表评审

> 日期：2026-09-05
>
> 范围：顶部航向带、滚转刻度、左右速度/AGL tape、横向偏移尺和底部状态。H3 中央飞行符号、地形、战机、碰撞、飞行范围与输入映射冻结。

## 原问题

- 顶部航向只有固定等距短线；航向数值变化时刻度本身不运动，视觉上更像装饰分隔线。
- 速度和 AGL 的当前值在 tape 顶部，另一个游标在下方运动；两处同时竞争“当前值”身份。
- 两侧 tape 的刻度固定不动，无法表达数值变化方向，也没有形成航空 HUD 常见的固定基准读数结构。
- 横向偏移尺没有标签，玩家无法仅凭画面判断它与 route cue 的语义差别。
- 外围元素已经接近圆屏安全边界，继续堆字或放大线条会压缩中央峡谷预判区。

## 设计决策

1. 顶部保持 `HDG xxx` 三位当前航向；下方改为连续滚动航向带：每 `5°` 一个刻度、每 `10°` 一个标签，四个正方向使用 `N/E/S/W`，其余标签使用两位十度数。
2. 航向带以屏幕中心为固定机头基准，刻度按真实航向连续平移，而不是跳格；固定下三角只表达当前基准。
   三位数字仍按整度显示，但刻度必须使用未取整的浮点航向；禁止让读数格式化精度反向限制动画精度。
3. 速度和 AGL tape 的当前读数框移动到各自垂直中点，成为唯一当前值基准；刻度相对读数框滚动。
4. 速度 tape 每 `5` 速度单位一个小刻度、每 `10` 单位一个主刻度；AGL 先换算为 HUD 已采用的十分之一模型单位，每 `1` 单位一个小刻度、每 `5` 单位一个主刻度。
5. 两侧 tape 不增加整列数字，避免圆屏边缘文字拥挤；当前值框、刻度运动和主次线长已经能表达量值及方向。
6. 横向偏移尺增加低亮度 `XTK` 标签；保留现有 V 形位置标记，避免与菱形 route cue 混淆。
7. `VR-01`、`EXT/HUD`、输入、姿态和推进状态继续使用已有真实语义；不增加武器、导航模式、垂直速度或能量等无数据来源项目。
8. 警告、撞击与输入失联仍可使用暖色，但常态外围仪表保持 HUD 绿的三层亮度，不与青蓝地形争夺一级焦点。

## 布局边界（468 × 466）

- 航向带：中心 `x=234`，有效宽度 `132 px`，轴线 `y=63`。
- 滚转刻度：中心 `y=112`、半径 `30 px`，不下压 H3 地平线。
- 左右 tape：轴线 `x=45/423`，范围 `y=160..264`，当前值基准 `y=212`。
- 当前值框：维持窄幅等宽数字，不越过半径约 `202 px` 的核心安全圆。
- 第三人称 `XTK` 保持 `y=230`，第一人称保持 `y=330`；仅补充标签，不移动战机或中央地平线。
- 底部状态基线保持 `_height-48`，不改变系统退出手势与提示。

## 真机 Review 重点

1. 航向带是否像真实连续刻度，而不是跳动的装饰线。
2. 速度和 AGL 当前值是否能在一眼内找到，变化方向是否自然。
3. 两侧 tape 是否保持克制，没有遮蔽峡谷预判区。
4. 第三人称和第一人称中央符号是否仍维持 H3 已确认关系。

## 退出条件

外围仪表形成“顶部方向、两侧量值、下方状态”的稳定框架，所有运动刻度均由真实状态驱动，并在圆屏安全区、双视角和警告状态下保持可读。
