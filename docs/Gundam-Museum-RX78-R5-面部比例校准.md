# RX-78-2 R5：面部比例校准

基线 `1b2fc26`（R4），分支 `feat/gundam-museum`。用户指出 R4 面部比例仍然错误。本轮集中修改头部，保留身体、装备、交互和生产光栅器。

## 参考与问题定位

新增并实际查看 [同款 HGUC 191 Revive 的头部近照](https://schizophonic9.com/re3/hguc_rx78.html)：`hguc_rx78022.jpg` 正面、`hguc_rx78021.jpg` 侧前方、`hguc_rx78004.jpg` 面罩与眼部内件。这组照片用来判断比例和前后层次；未涂装的火神炮、脸侧槽、摄像窗不作为游戏分色标准，分色继续参照官方成品照。

R4 的主要错误是面罩过宽、眼睛过长、红色眼下区域太薄、下巴宽短，以及脸颊内侧缺少收拢面罩的白色护框。侧面还显示面罩比眉檐更靠前。继续补槽线无法解决这些问题。

新增 `face-front / face-quarter / face-side` 三个独立头部视角。使用不带身体侧倾的已有姿态，仅筛选 Head 部件，固定相机和尺度；在修改前先用 R4 模型生成基线。旧、新图都是实际 C++ 资产通过生产光栅器绘制。

## 本轮修正

- 面罩外轮廓宽从 0.212 缩至 0.140，头壳最大宽 0.348，对应约 **61% → 40%**。下缘向红色下巴收拢，中央折面和两条口槽重新定位。
- 黄色眼睛的左右总跨度从 0.206 缩至 0.146，约 **59% → 42%** 头壳宽。黑色眼窝和红色眼下区域分别成面，恢复眼间黑区；去掉过低的白色眉心尖角。
- 下巴最大宽从 0.072 缩至 0.044，约 **21% → 13%** 头壳宽，并延长下巴形状。头壳下半部的纵向比例从 0.84 调到 0.79，维持冠顶高度并增加颈部空隙。
- 增加脸颊内侧白色护框，调整脸侧壳深度，补齐其与后头壳之间的连接。眼窝、面罩收进眉檐之后，红色下巴保留向前伸出的轮廓。
- 额冠和额前红色件增高，V 天线尖端跨度从 0.414 调至 0.490，对应约 **1.19 → 1.41** 倍头壳宽；以新正面参考纠正之前受斜视照片影响的短天线。

以上百分比是**模型坐标中的部件比例**，用于记录修改幅度，不是照片相似度、三维扫描尺寸或视觉通过率。前视参考按头壳大致宽度等比配准，摄影镜头和头部姿态仍有差异。

## 两轮复核

结构轮检查独立头部的正面、侧前方与侧面。第一版收窄面罩后，仍存在眼睛偏长、眉檐前后关系不对和脸侧壳断开的情况，继续修正。最后的并排图又暴露了过低的眉心尖角和过高的红色鼻梁上缘，已把眉檐拉平并恢复两眼间的黑色区域。

显示轮检查固定生产相机下的头部特写、全身和灰模。保持真实模型像素，不用生成图或修图替代运行结果。曲面和面罩下缘仍有分面感，微小倒角及柔和高光不等同于实物摄影；本轮结论是上述比例错误得到修正，不宣称全角度实物复刻。

## 验证与证据

最终模型通过 ASan／UBSan 下 **2,592 组**渲染组合、输入控制和重新进入检查：埋藏端盖补回为 0 像素差异，局部／全量重画为 0；剔除前后累计 256 个边界像素差，单帧最多 6，内部差异为 0，阈值未放宽。

模型为 **4,045 panels**，补回 32 个端盖为 4,077，容量仍为 4,096；工作区仍为 **710,712 B**。脸侧槽两条不间断的平面边框改为整条生成，减少不必要的切片。本轮没有改动共用光栅器，也没有重复运行上轮已通过的整套其他游戏回归。
