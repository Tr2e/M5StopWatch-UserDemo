## 1. 本阶段边界

M6 在已通过的曲线标架上只恢复确定性的地形事件流与运动：

- 固定种子 `0xC4A71001`；
- 左右悬崖按 S-gate 顺序独立向通道内突出；
- 34 slice 固定缓存随前进循环回收；
- 每 20 秒安排 15 秒巡航和 5 秒高速，共覆盖三段高速窗口；
- 继续关闭 IMU、按钮输入、碰撞、战机与 HUD；
- 保留退出应用的系统按键。

目标是把接缝、事件连续性、LOD 和性能问题与游戏控制完全隔离。

## 4. 首轮真机性能发现与修正

首轮视觉 Review 正常，但串口日志显示 FPS 会随累计 segment 增长而下降：最初约 25 FPS，长距离运行后最低降至 13.1 FPS。同期 render 始终为 37–40 ms、栈水位始终为 2740、初期 clamp 为 0，定位到旧的全局弧长反解每生成新 slice 都从路线原点重新积分，成本随里程线性增长。

本阶段没有放宽 `>=24 FPS` 门槛，也没有提交首轮版本；改为基于已缓存末端 route parameter 的局部增量反解，并重新执行上述 host 与 sanitizer 门禁。以下构建信息对应性能修正版。
