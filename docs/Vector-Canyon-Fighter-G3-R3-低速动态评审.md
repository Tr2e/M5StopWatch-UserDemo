# Vector Canyon Fighter · G3-R3 低速动态评审

## 结论

R3 于 2026-09-01 经 StopWatch 实机视频复测通过，可以进入 R4 高速穿梭、战机与 HUD 阶段。

## 首轮阻断问题

首轮动态测试出现明显的近景网格周期性收缩和整排重连。视频逐帧检查确认问题不是地形函数随机变化，而是切片回收时机错误：

- 最近切片在 `z < 0.98` 时仍清晰可见；
- 回收后，下一排切片的深度立即增加约一个完整切片间距；
- 近景沟底因此发生可见跳跃，破坏连续穿梭感。

## 修复

- 将切片保留到相机后方再回收。
- 在固定近裁剪面 `z = 0.22` 上，对相机后方切片与前方切片进行线性插值。
- 投影数组最多增加一排虚拟网格，继续使用固定容量数组，无逐帧动态分配。
- 回收前后的近裁剪面几何保持一致，不再跳过一个切片间距。
- 正式帧节拍设为 50 ms；设备全画布刷新约 53 ms，因此有效帧率稳定在约 19 FPS。

## R4 入口条件

R4 应在已验证的连续地形流上完成：

- 高速/BOOST 运动节奏与速度感；
- 原创长机鼻、四分翼、四引擎线框战机；
- 圆屏边缘 HUD，中央峡谷视区保持通透；
- 高速状态下再次检查切片回收连续性；
- 保持 `InputProvider` 接口不变，为后续 Joystick2 与按键硬件接入留出替换点。
