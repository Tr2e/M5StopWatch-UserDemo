# 高达博物馆极简展示界面

按用户最新要求，画面仅保留模型和左右两侧切换箭头。删除标题、收藏编号、机体名称、顶部返回文字、AUTO、RESET、分隔线和底部提示。正常画面不绘制文字；内存申请失败仍有错误提示。

## 交互

左右箭头热区为(8,201,48,64)与(412,201,48,64)，绘制与触摸共用边界。松手确认、移出热区取消。其余区域均可开始拖动，包括原 AUTO/RESET 的位置；从模型开始的拖动滑过按钮也不会切换高达。松手后保持角度，不自动旋转、不惯性运动；旧自动切换事件和确认键复位均不再生效。机身 A 短按仍可切换，长按 A 或退出和弦可离开 App。

为避免影响赛车的 view-car 模式，增加独立 MuseumInspect 输入上下文；CarInspect 的 AUTO、RESET 和原箭头热区不变。复用现有独立采样、释放门禁、失效取消与关闭/重入机制，未修改电源或外设驱动。

## 显示

原模型区352×288扩大到424×424，位于圆屏中央；内部最高光栅也提升至424×424，静止按100%绘制、拖动65%，不是单纯拉伸原图。模型固定相机尺度：RX-78 76→98（约29%），Nu 65→78（20%），Strike 65→82（约26%）。角度变化不触发自动缩放。Nu 在更大的初始尺度下有附件碰到绘制边缘，已调整留白并检查整个旋转范围。

Nu 背包安装边缘在放大后暴露了几个量化覆盖缺口，生产渲染对此部件保留双面，最终剔除与完整参考图的内部差异为0；三款模型几何和比例没有修改，文件哈希见证据目录。

渲染工作区从710,712 B增至1,024,312 B，多313,600 B；仍在打开 App 时申请、关闭时释放。扩大显示区域也同步更新了直接绘制和 Canvas 路径的局部刷新范围，旋转和切换时不会遗留旧画面。真机帧率尚未测量。

## 验证

- 三款分别864组姿态/质量/装备/特写组合，共2592组；内部剔除差异、补回埋面差异、局部刷新差异均为0，既有边缘差异阈值未放宽。
- 每款完整装备100%档的24个方位×3个俯仰，均未触碰圆屏230像素安全半径或424绘制区边缘。特写裁切为离线诊断，不进入产品切换。
- 输入测试覆盖两侧点击、滑出取消、模型拖动跨越按钮、旧热区失效、松手保持角度、慢帧手势只消费一次、输入失效、退出与重入。
- 旋转后的局部刷新与完整刷新逐像素一致；跨机体缓存、十次关闭重开及正常画面无文字均验证。
- Racer、Vector Run、Launcher、共享设备输入与生产渲染器完整主机测试通过。测试所需字体头通过本机已安装的 M5GFX 依赖路径提供，未改动共享依赖目录。

证据位于 [gundam-museum-minimal](assets/gundam-museum-minimal)，包含主机日志、三款原生图、48视角离线旋转图以及固件摘要。离线旋转图通过相机采样生成，产品本身没有 AUTO 模式。

当前为主机和构建验证；尚未烧录，实际触摸手感、帧率和设备显示效果待真机确认。模型制作卡中的旧带文字截图保留作历史记录，当前产品合同以本文为准。
