## 1. 本轮边界

第一轮只调整颜色语义，不改变 M8 已确认的峡谷几何、游戏 HUD 布局、战机位置、阴影尺寸、操控和碰撞参数。校准页发现原有文字使用固定像素偏移、没有按字体宽度居中，因此在同一 UI 阶段单独修正启动界面。

## 2. 色彩语义

| 层级 | RGB | 用途 |
| --- | --- | --- |
| 地形近景 | `36, 127, 145` | 低亮度青蓝世界线 |
| 地形中景 | `21, 76, 91` | 纵深衰减 |
| 地形远景 | `9, 40, 50` | 接近黑色背景 |
| HUD 主色 | `114, 230, 162` | 航空磷光绿 |
| HUD 次级 | `39, 94, 69` | 刻度、辅助线、标签 |
| HUD 高亮 | `182, 255, 208` | 当前值、飞行路径和基准点 |
| 战机主体 | `228, 238, 235` | 冷灰白视觉主体 |
| 战机结构暗线 | `84, 107, 106` | 内部结构和轮廓阴线 |
| 座舱 | `101, 183, 200` | 与世界层关联的冷青色 |
| 尾焰 | `155, 225, 236` | 常态冰蓝白 |
| 预警 / Boost | `255, 179, 71` | 仅状态变化时出现的琥珀色 |
| 撞击 | `255, 88, 72` | 只用于真实碰撞的红橙色 |

核心约束：绿色只属于 HUD，青蓝只属于世界和推进系统，灰白只属于战机，暖色只属于需要注意的状态。科技感由单色层级、线框密度和负空间建立，不依赖多色霓虹。
