# Vector Canyon Fighter：G3-P1 IMU 姿态输入评审

> 日期：2026-09-04  
> 目标：提高临时 IMU 操纵的即时性、可控范围与回中稳定性，同时保持最终 Joystick2 接入所使用的 `FlightInput` 契约不变。  
> 非目标：不修改战机几何、姿态动力学、相机、地形和碰撞。

## 实现结论

- BMI270 的 100 Hz 加速度计与陀螺仪均沿用现有 HAL，不修改系统级驱动和轴映射。
- 重力姿态角提供长期基准，陀螺仪提供快速动作响应；加速度模长偏离 1 g 时降低重力修正权重，避免平移动作被误判成倾斜。
- 启动校准同时记录姿态零点和 X/Y 陀螺零偏；2.5 秒窗口不稳定时自动重新采样。
- 六轴数据通过无锁奇偶序列发布为一致快照，避免主循环读取到跨帧混合数据。
- Provider 内部输出统一为 `steer/pitch ∈ [-1, 1]`：3° 死区，左右 28°、俯仰 26° 达到满量程，并施加轻量中心增益与输出低通。
- 无效帧、连续错误和超过 300 ms 的陈旧样本进入 `Fault`；`FlightModel` 仍只读取通用输入，不感知 IMU 角度或硬件类型。
- 重力无法提供绝对航向，因而不积分无锚定的 gyro Z；航向仍由通用 steer 指令和飞行模型生成，避免长期漂移。
