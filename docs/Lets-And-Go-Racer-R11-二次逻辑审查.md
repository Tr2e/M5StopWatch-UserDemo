# R11 二次 CR：比赛与输入逻辑

基于完整计划与 R0–R10 逐项复查。此次审查发现旧文档中的“完成”并不等于实现正确，以下以生产代码和新增回归为准。

## 第一轮自审与修正

- P1：原先每辆车在自己的发车距离 + 3 圈完赛，实际终点不统一。所有格位移至共同起终点后方，穿过 s=0 开始计圈计时，s=3L 完赛。
- P1：暂停页红键短按通过 `back()` 回到 Racing，但物理控制器仍暂停。移除该路径，只允许统一的长按暂停/恢复。
- P1：机身 GoNext 可以绕过外设检查和校准。移除调试跳过，必须由真实 readiness 推进。
- P2：双键退出同时触发暂停/增压。和弦独占按键动作，摇杆失联时保留有效按键的退出通道；失效按键不能触发退出。
- P2：菜单红键长按未返回；无效的机身导航会重置倒计时；恢复暂停会重放 GO。分别修正。
- P2：同时刹车与增压消耗电量。刹车优先，增压不再生效。

## 第二轮自审与修正

- P1：同一物理步内冲线原按数组顺序判定，对手固定优先。增加亚步长过线插值，按真实 crossing time 排序；完全相同时间稳定打破平局，名次不重复。
- P1：异常 RaceSetup 含玩家自身/非法掩码可能越界四车数组。控制器入口过滤并回退非法车型。
- P2：套圈车辆按绝对距离判断，物理接触和 AI 避让漏检。改为闭环距离余数；排名仍按累计距离，不能混用。
- 新增共同终点逐步断言、插值计时、名次唯一性、同帧冲线顺序、非法 setup、暂停冻结、按键独占/失联退出、刹车不耗增压回归。
