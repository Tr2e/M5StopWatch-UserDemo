从 Let's & Go!! 八台赛车的线框、实体建模、UV 涂装、多轮结构返工和生产回归中提炼。以后新增或优化赛车、战机、机械模型，从这里进入；通用方法与 StopWatch 实现约束分开维护。

## 以后如何开始

可直接说：**“按我们的模型制作资产库新增／优化〈型号及版本〉，沿用结构与材质卡，逐台完成两轮自审，交付生产证据。”**

在本项目还必须遵守 [车型建模与优化规范](Lets-And-Go-Racer-车型建模与优化规范.md)；它规定设备预算、坐标、操控不变项和具体命令。跨项目则先确定新引擎／格式／设备预算，不带过去这里的固定轮组尺寸或面数门槛。

## 维护和安装

仓库 `skills/reference-model-workshop/` 是版本化源；个人技能目录的同名文件夹是可发现安装副本。更新时先改仓库源、执行脚本自测和技能校验，再检查并同步安装副本；有本地差异先核对，不静默覆盖。仓库副本可随项目版本回退，安装副本不自动随 git 更新。

依赖 Python 3.10+、Pillow（证据工具）；技能结构校验脚本另依赖 PyYAML。生产建模和游戏不依赖 Python。工具包没有打包参考照片，也没有新造外部贴图文件：游戏沿用 UV 程序涂装。已有品牌车型仍仅供私人游戏；通用方法复用不等于品牌素材再分发授权。
