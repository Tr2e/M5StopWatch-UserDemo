## 1. 沙扎比 SDEX017

参考沿用专项检查已实际打开的万代同款正/斜/背商品图，另实际查看 [同款实物头部正斜近照](https://gunplapocchi.com/wp-content/uploads/2020/12/SDEX-SAZABI-11.jpg)（[原作者评测](https://gunplapocchi.com/sdex-sazabi/)）。实物贴纸说明颜色和轮廓，不将贴纸叠层照搬成三维镜片。图像支持斜窗中央容纳单眼、两端变窄；下述单位均为建模参数，不是官方尺寸。

- CR1：旧黑带等宽 `.037`，单眼凸于眉缘。改为中央高 `.085`、中段 `.0525`、末端 `.020` 的曲面斜窗；窗口后壁退 `.070`，单眼前端从 `.577` 退到 `.490`，后端 `.465` 插入后座，中心高度 `2.452`，镜片前半径 `.035`。保留三红角和额头摄像窗的独立身份。
- CR1 返修：第一版下眼框叠到旧面具上缘，正斜图出现重复折线；接边后非共面四边形又产生交替三角明暗。改成沿眼窗边界汇入中央脊的三角扇，下面具用左右两个平面薄壳，共享 `(0,2.37,.58)` 与两侧挂点。原颈柱、面具后梁及背板保留，未靠前移眼睛遮丑。中间版先看 `r1/r3` 正斜侧，最终看 `v4` 全套。
- CR2：实际查看最终正/斜/侧、另一侧斜视、俯/仰眼区、头颈装配图；全部11张原生诊断图与48帧完整装备转台。核对单眼位于上下边界内、侧面不再凸出眉檐、下眼框到尖面具连续、头颈支撑、身体装备与圆屏留白。100%/65%均可辨单眼；正侧视逐渐被眉甲遮挡属于嵌入后的正常遮挡。此次没有宣称真机视觉/FPS通过。
- 技术：ASan/UBSan 864组通过；眼窗中段射线、单眼中心及十个周界采样均检查完整头部最前面；单眼前移、黑窗前移受控负例被检出。既有头/面具断连负例、枪盾/炮阵/拳壳零异常相交通过。最终4059面（旧4057），容量4096、工作区1274184字节不变；内部/埋面/局部刷新差异0，剔除边缘累计23、单例最大4，完整装备圆屏/视口越界0。

最终证据：`docs/assets/gundam-eye-refine-20260915/sazabi/`，包含前后对照、原生图、结构图、相机、测试结果和48帧GIF。中间 CR1 图为临时诊断，最终档案只收当前生产资产输出。

## 2. ν 高达 BB387

沙扎比在 `a2e8f9d` 提交后才修改本台。沿用已认可的BB387制作卡，补看 Dalong 同款 [组装正斜图07](https://www.dalong.net/reviews/sd/b387/p/b387_07.jpg) 和 [卸下头盔图16](https://www.dalong.net/reviews/sd/b387/p/b387_16.jpg)。保持无瞳绿眼，不引入拆件图另一面的瞳孔方案。

- CR1：黑底叠绿片替换为连续眼窝。首版沿旧黑底开口制作，绿眼变得偏高，且完整头部近角点射线实际失败：外角 `x=-.30027,y=2.41295` 的镜片前方有白颊甲。恢复原绿色四角XY轮廓，以反算口沿的方式补厚度；颊甲内点从 `.27` 外移到 `.335`，回接下眼框与原面罩上缘，不前移镜片。
- CR2：斜俯近景发现新外侧回接片越过旧眉檐外边，形成局部锯齿。将回接分成眼角→眉端，以及眉端→颊壳两段，使用原眉檐端点共享边界。最终重新看两斜/俯仰眼区、原生11张与48帧完整装备转台，未发现新的盖眼、凸片、断连或装备/圆屏回归。绿眼保持宽大轮廓，正侧被侧甲遮住，不再露出前贴绿板。身体比例、下巴、三条口槽、四天线均未重做。
- 技术：共享四角眼窝只新增调用，不修改命运/强袭实现；`NuAssembly` 增加可选眼窝面范围，无运行时缓存增量。深度在头部缩放后按 `z0=.515×1.02`、`slope=.35×1.02/1.08` 检查，镜片实际退入 `.06528`，高宽比 `.556364`；中心、55%/90%近角点、连接和前移/盖面负例通过。ASan/UBSan 864组通过；头身比2.71379、头深宽比.979249不变；装备异常相交0，盾/炮挂点及受控错误仍能检出。
- 最终3636面（旧3654）；内部/埋面/局部刷新差异0，剔除累计62、最大4；完整装备圆屏/视口越界0，工作区不变。证据清单通过。`idf.py build` 通过，应用 `0x3d3b00`，分区余量22%。

证据：`docs/assets/gundam-eye-refine-20260915/nu/`。`nu_gundam.cpp` SHA-256：`602aceb56d9f344ee461d4ac915dc7c3bac9b33c27666f4d3198f9d016d38685`。

## 3. RX-78 用户基线 / SDCS 结构

ν 在 `98e691e` 提交后才修改本台。保持用户认可的正面比例、站姿、金色无瞳大眼与红色眼间区域；SDCS资料仅解释结构，不替换用户基线。本轮另实际看过 [同构型成品02](https://www.dalong.net/reviews/sd/cs01/p/cs01_02.jpg) 与 [拆甲04](https://www.dalong.net/reviews/sd/cs01/p/cs01_04.jpg)，成品中的瞳孔不引入当前无瞳风格。

- CR1：拆除覆盖两眼的整块红B2底板、黑平面和彩色贴盖，保留五个原金色轮廓顶点的XY。将通用组件扩展为凸平面多边形，五角光学面分3个三角面，四角调用仍保留原四边面；口沿→内壁→镜片斜边连续。首版回接面跨过外下眼角，完整头部射线检出 `x=-.233928,y=2.1748` 前方遮挡（镜片z=.36102，前面z=.41849）。将下缘与外缘回接分开，颊甲内缘外移至`.335`，没有缩眼或前推金片。
- CR2：正斜/俯仰图继续发现上外眼框的小三角空隙，以及红色中央插片穿过面罩形成的多余下唇。改为鼻梁直接共享两个眼窝内缘和原面罩中央点，上眼框共享原眉檐边界，补齐外角三角回接。最终重新看正/斜/侧、对侧斜面、俯/仰眼区、全部11张原生诊断图及48帧完整装备转台。确认五边金眼、两条口槽、红下巴、白V角、脸宽及头体比例保留；眼后无红盖面，侧面金片不突出头壳，眼框到眉/颊/面罩连续。未改变整体相机或主页面尺寸。
- 技术：新增 `Rx78Assembly` 可选诊断范围和本款五角守卫，逐点验证原轮廓XY经过生产头部变换后的结果，而不是套四角比例。检查真实镜片退入`.064`、边界连接、中心和五角55%/90%采样；前移/额外盖面两类负例在两眼均能检出。ASan/UBSan 864组通过，最终3288面（旧3284）；内部/埋面/局部刷新差异0，剔除累计64、最大3；装备异常相交、完整装备圆屏/视口越界均0。既有头身/脸深/天线与足底检查不变。

证据：`docs/assets/gundam-eye-refine-20260915/rx78/`，清单检查通过。`rx78.cpp` SHA-256：`25d5298f46932c140c4465e9200249b1e12f5cc4dd198328659865706d48afa8`；共享 `sd_eye_socket.h`：`0e0ff1002a5bba2570fc6e855e24d006cd70bd7464e00b695d3dff9abdeb22fb`。
