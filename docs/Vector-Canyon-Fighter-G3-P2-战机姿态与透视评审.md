# Vector Canyon Fighter：G3-P2 战机姿态与透视评审

> 日期：2026-09-04  
> 目标：让左右、升降操纵在第三人称线框战机上形成明确、合理且稳定的三维姿态反馈。  
> 非目标：不修改输入硬件契约、战机基础网格、峡谷生成、碰撞范围和玩法规则。

## 问题复核

旧实现只有最大 ±18° 滚转和 ±12° 俯仰，且采用恒定角速度逼近；左右移动没有局部偏航，因此更像一张线稿随峡谷横移。投影只执行 roll 和 pitch，无法利用机鼻、翼尖及四发动机的透视差表达转向。

## 实现决策

- 最大视觉滚转调整为 ±30°，最大视觉俯仰调整为 ±18°。
- 新增最大 ±8° 的局部 `turnYaw`，仅描述战机相对航道的瞬时转向姿态，不替代累计航向。
- roll、pitch、turnYaw 使用临界阻尼二阶响应；保持输入时稳定收敛，松手后自然回中且不产生故意过冲。
- 战机顶点统一执行 roll → pitch → yaw 的三维旋转后再进入同一透视相机；偏航不再是屏幕空间平移。
- P2 当时将相机俯仰跟随由 12% 降至 8%；G4-H1 在 HUD 共形实机评审中提高至 18%，让世界地平线变化可读，同时仍保留大部分机鼻相对姿态。
- HUD 继续读取同一 `FlightState.roll/pitch` 驱动滚转指针、俯仰梯和数字；局部偏航由战机透视、航向和航道标尺共同表达，不增加拥挤的第三套数字。

## 接口与路线校准

P2 仍只消费 `FlightInput` 的规范化轴。IMU、Joystick2 或其他输入源不会进入姿态方程和投影器；Renderer 也没有读取 HAL。新增 `turnYaw` 属于通用飞行视觉状态，后续外设接入无需修改战机投影。
