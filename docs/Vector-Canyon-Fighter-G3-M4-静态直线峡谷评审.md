## 3. 静态模型门

`resetStraightBaseline()` 强制：

```text
centerX = 0
centerZ = worldS
tangent = (0, 1)
leftWidth = rightWidth = 2.18
eventWindow = empty
playerWorldS = 0
```

即使调用 `update(100000)`，segment、相机位置和模型都不变化。生产曲线路线与事件算法仍保留并通过回归，但在 M4 不参与画面。

增加一个 mode bool 后 `ExplicitCanyonStream` 从 1200 B 变为 1204 B，仍低于 1280 B 编译期上限。
