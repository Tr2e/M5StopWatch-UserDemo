## 材质与 UV 卡

| 范围 | 既有采样 | 比赛处理 |
| --- | --- | --- |
| 纯色、橡胶、实体内腔 | RGB565 + 面片 light | 保持原纯色通路，不进纹理表 |
| 车壳条纹、灯、玻璃、翼面字样 | 程序 `carPaintColor(paint, base, u, v)` | 32×32 RGB565，在 texel 中心采样，并预先应用面片 light |
| UV、左右映射、轮组 | 生产面片属性 | 不改变；透视插值与近裁剪继续保留 |
| 车库展示 | 完整程序材质 | 保留原计算与原图 |

无 mip 链、无纹理压缩、无额外透明车壳。最近邻采样会使小字和高频细纹变粗或消失；32×32 不是每辆车的最终屏幕尺寸，而是每种程序材质变体的 UV 采样分辨率。

缓存 key 同时包含 paint、底色和 light，防止不同车或明暗面串色。最多 64 张纹理，固定 131460 B；纹理只在参赛车型或几何档位改变时重建，逐帧不分配。容量耗尽或分配失败回退到原材质。比赛 234×233 场景与 468×466 HUD 维持第十版设置。

## CR1：结构与采样契约

完整几何／轮胎净空／三档身份检查通过；未修改生产模型或部件库，182 张原有截图逐字节一致。核对了八车型的肩线、开口、翼面与轮组仍由原几何定义。

材质测试覆盖所有非纯色 paint、两种底色、223/255 两档光照的全部 32×32 texel，与原程序在相同 UV 的结果逐像素一致；检查 UV 边界钳位、容量溢出回退和 clear 后失效。低分辨率采样本身的误差不当作采样器错误。

## CR2：生产显示与回归

实际打开查看两组原尺寸拼图，分别包含 0–3 和 4–7 车型的原程序、比赛烘焙和近距离对手图。主要色块与剪影保留，细字和小灯纹更粗，符合本次允许的比赛降质；HUD 与小地图保持原生清晰度。

新增比赛测试覆盖八车型、两条赛道、单人/四车、不同几何档位、车作为近距离对手、关闭后重入；缓存与原小地图在圆内像素一致。最初证据清单错误地把新增比赛帧当作已有基线帧，已拆成“原车库与基线比对”和“新增比赛身份/帧检查”两份清单并通过，没有伪造缺失基线。

## 第十二版修订：玩家原生，降质集中在对手

第十一版真机反馈：玩家马赛克感过强，主机截图通过并不等于设备画质验收通过。按用户新要求，玩家退出 32×32 材质表，以 Medium 模型和原始程序涂装在原生 468×466 画布绘制。对手保留烘焙涂装，改为 Minimal 几何；两者继续使用同一生产模型、材质、UV 和栅格器。

CR1：首次尝试六段圆周，使 Cobra 凹口检查不再成立。修正为八段圆周，进气口独立保持至少六段，八车的四档关键结构/穿胎/镜像 UV 检查通过。对手面数依次为 616、649、595、781、615、595、821、711；未删除尾翼、空槽、内壁或灯位。主比赛缓存 904824 B，纹理表和小地图缓冲不变，车库缓存不变。

CR2：打开查看八车原生玩家、旧版半分辨率玩家和近处对手的两组生产图。玩家车轮廓、玻璃边缘和车壳图案更清晰；对手轮/导轮更粗，符合本轮取舍。按远到近顺序分两阶段合成，原生车辆使用缩放后的赛道遮挡查询；比例遮挡测试与重入/玩家身份切换检查通过，防止玩家总盖在对手/桥面上。高速固定快照改变时间的图像一致，验证速度线已移除。

完整回归与目标构建通过；基线只有 17 张含速度线的图片变化，逐像素检查均为原速度线颜色删除。增加 16 张实际分层策略的比赛图并重新跑八车证据工具；车库仍逐像素一致。原生玩家观感、实际设备遮挡和 FPS 待本轮设备测试。
