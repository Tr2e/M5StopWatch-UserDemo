# SD RX-78 制作全过程与后续模型执行基准

2026-09-14。范围：从 HG 转为 SD、用户比例基线重定、头脸/天线返修、身体体积与枪盾装配，到 v5 站姿和单展品浏览。本文保留原因和证据；后续建模直接执行 [Pipeline 的 SD 路径](../skills/reference-model-workshop/references/pipeline.md)，填写 [制作卡](../skills/reference-model-workshop/assets/model-card.md)，无需重新经历这些错误。

## 当前认可范围

v4 后用户反馈“这次结果挺好的”，随后要求单展品浏览和新站姿。v5 完成并烧录后，用户反馈“好”，要求将整个过程固化供后续模型复用。因此以 **RX-78 v5 的形体完成度、装配方法、站姿制作及检查闭环**作为后续 SD 模型基准。用户基本认可不等于所有官方照片精确重合，更不等于设备 FPS 已测。

原正面图仍决定比例。追加的体积实拍只用来指出问题；后来的站姿图明确用于姿态。官方/同构型多角度成品和说明书用于结构。用户原比例图的精确出处未确认，SDCS 对应关系属于有资料支撑的判断；不能重写为已确认某张官方封绘。SDEX v1 的商品选择及旧比例已经被新基线替代。

## 实际经历的五轮

1. **v1，独立 SD 重建。** 沿用 C++ Mesh 与软件光栅器，重建头、胸、短肢和大脚，补板件和说明书。内部迭代修了额冠穿眉、膝部条纹、摄像头、顶冠、颈圈及格栅。技术自检/烧录完成后，用户指定另一张比例图，原比例结论失效。[原计划与执行记录](Gundam-Museum-SD-RX78-改造计划与自检.md)
2. **v2，按用户图校正正面。** 收窄增高头壳，拓宽胸肩，缩短露颈，加宽扁足；调眼区、下巴、口槽、额片及 V 翼。正面数字与技术测试通过，但用户指出“头太扁、天线看起来基本一样宽”，证明侧面体积和中间截面验收遗漏。[基线差异](Gundam-Museum-SD-RX78-用户图比例验收基线.md) · [v2 退回记录](Gundam-Museum-SD-RX78-V2-逐步修正与烧录.md)
3. **v3，头壳与天线。** 增加后脑中段体积和上下收口；V 翼改为五段宽厚渐缩截面，保留小钝端。用户确认头“不单薄”后指出身体和装备仍有问题，不能扩大为整机验收。[v3 记录](Gundam-Museum-SD-RX78-V3-头壳与天线返修.md) · [头壳前后图](assets/gundam-sd-rx78-v3/head-before-after.png)
4. **v4，身体体积与真实装配。** 补同构型说明书、拆甲和盾背资料，重做胸截面与宽颈圈，加厚肩/前臂/腰裙；枪与手共用坐标，盾板经 U 形支架连接。相交检测检出 v3 的 442 对非预期相交面，修到 0；薄金色插片再修剔除缺像素。用户反馈结果挺好。[v4 记录](Gundam-Museum-SD-RX78-V4-身体体积与装备装配.md) · [胸甲对照](assets/gundam-sd-rx78-v4/chest-before-after.png)
5. **v5，姿态与产品收敛。** 增加肘部层级，屈肘向外持枪，双足外展并略错前后，盾板外倾并露出持盾手；每台只保留完整装备浏览，诊断视图留在主机。三模型回归通过、同一设备烧录启动后，用户要求将模式复用。[v5 记录](Gundam-Museum-SD-RX78-V5-单展品与站姿.md) · [参考/旧版/新版站姿](assets/gundam-sd-rx78-v5/pose-comparison.png)

## 错误清单：现象、修复和下次如何提前截住

下列编号用于制作卡追溯，不是照抄 RX-78 参数的清单。每项都已在主 Pipeline 的对应 SD 节点规定动作。

### 参考与全身比例

- **E01 风格与版本继承错误风险。** HG 的“头大”投诉不能直接转换成 SD 缩头；SDEX、SDCS 也不是同一比例。实际先独立 SD 重建，后按新基线替代旧比例。下次 G0/G1 锁定风格、构型和各图用途，禁止沿用不适用的旧通过结论。
- **E02 把问题实拍升级为建模基准。** 用户追加实拍指出胸甲不丰满，并明确纠正它不是新的模型依据。之后改用官方/同构型多角度结构资料。下次先标“问题提示”或“姿态/比例依据”，不能仅凭收到新图就换版本、尺寸或配色。
- **E03 头宽扁、身体小。** 新基线中头宽需收、头高需增，胸肩宽高不足；单个三维头身比曾掩盖二维差异。实际分别调整头壳、胸腹和肩轴。下次 G2/G3 分列投影与三维指标，等高比较头、肩、胸、腰、脚，不整体缩头了事。
- **E04 颈长与肩低。** 下巴和胸口之间露出过多颈轴，破坏 SD 紧凑感。通过胸顶、头底、肩轴联动和宽颈圈修正。下次正面记录下巴—颈圈—肩甲关系，不能抬相机藏脖子。
- **E05 腿修长、脚窄且鞋头高。** v1 先主动缩短腿链并同步下移上身，v2 再按新图重建宽扁脚和踝甲；脚朝向另行校正。下次区分肢体长度、鞋截面和脚投影，不能每次都继续压腿，也不能让脚踝脱节。

### 面部、头壳与天线

- **E06 眼扁、下巴长、口槽及额片不符。** 新基线暴露细长护目镜感、过长下巴、三道口槽与宽额片。v2 调眼角/眉檐/眼区高度，缩下巴，口槽三改二、额片收窄。下次 G4 按本款头宽归一化逐项核对，槽数和比例不能套通用高达脸。
- **E07 面罩突出头盔的侧面问题。** 早期通用模型反馈已明确指出，SD 重制持续保留该项检查。先测眉檐、眼窝、面罩和颊框的空间层次，再看侧面；最终未靠推脸增强正面辨识度。下次检查几何和参考，不能先把它归咎于透视或换相机遮掩。
- **E08 头壳正面合格、侧面仍扁。** v2 的宽高与端点检查漏过后脑体积。v3 调后脑中段最大截面、上下收口和颊壳连续性，面罩前缘不前移。下次 G3/G4 同时签正面比例和侧面体积，不能“正面进区间”即通过。
- **E09 天线针尖/等宽条两个方向都错。** 用户新基线要求不过尖；v2 虽有小端面，中段宽厚变化仍不足。v3 用五段菱形截面形成宽根、薄梢、小钝端。下次分别查跨度、上扬、宽根、中外段宽厚和端面，按本款要求选择尖/钝，禁止仅测端点。
- **E10 红额冠穿眉、前摄像窗被遮。** 初版额片下尖与眉檐相交产生白洞，后一次额冠前缘又遮窗。重新校正额片平面/深度和窗口；下次 G4 正斜侧联查额冠、眉檐、窗口，不能当作像素噪声放过。
- **E11 顶冠悬空、后摄像头埋壳。** 顶冠内边回接不足形成拱桥，后窗仍按旧壳坐标放置。修正侧壁回接和前后开窗，后窗沿真实后壳定位。下次每次改后脑/冠带都复查背面、冠壳接触与凹窗。

### 胸甲、四肢与表面

- **E12 头厚了、身体仍是薄盒。** v3 只改善头部，胸甲厚度和中央胸块体积未同步。v4 对照 B8/B21 结构重建胸壳变化截面、凸胸块和宽颈圈。下次 G3 就要求整台体积成立，不能把身体留到用户再次投诉。
- **E13 肩甲、前臂、腰裙缺侧面厚度。** 正面色块看似齐全，斜侧却单薄。v4 分别补壳体深度和包覆；下次把这些部件与胸壳同轮检查，不能只加胸前一块。
- **E14 胸栅悬浮、细边断续。** 横栅与边框太近，边框缺回接壁；胸体积改变后还需同步凹槽深度。修正百叶位置、间距、回接四壁和真实凹腔。下次 G5 看正斜侧开口及旧面遮挡，黑色贴片不能当凹槽。
- **E15 小腿上盖穿膝轴、踝部连接易失配。** 初版膝部出现条纹，需下移小腿上截面露出独立关节；脚宽/角度改变时踝甲跟随。下次检查膝轴表面、开放踝口、鞋面和足底接触面，不只看正面腿长。

### 站姿与装备穿模

- **E16 枪柄与手掌不共轴，枪身切前臂。** v3 检出枪/前臂 36 对、枪/手 69 对相交面。v4 枪柄与握孔共用手部变换，恢复真实握孔与腕轴，并为枪身留前臂间隙。下次先建握持坐标与空区，再调整枪角，不独立摆枪和手。
- **E17 盾板切肩臂，缺正确支架。** v3 检出盾/肩 94 对、盾/臂 191 对、盾/手 52 对相交面。依据盾背 B16 支架重定位盾板并补 U 形连接；下次看盾背组合图和完整模型，不能只看漂亮的正面盾图。
- **E18 直臂站姿僵硬。** v4 的肩肘腕基本成一直线；只转肩无法得到参考的屈肘持枪。v5 增加前臂绕肘的刚体层级，枪随手腕，双脚外展略错位，盾外倾并露出持盾手。下次 G2 即记录目标姿态锚点，G3 做姿态灰模，G5 精调装备，不到最后才摆姿势。
- **E19 装配检查缺失，或豁免范围过大。** 旧渲染比较无法检出上述真实相交。新增独立三角面检测，并以旧版 442 对相交作为负例；正常插接限定在前臂接口小范围。v4 有 10 对、v5 有 4 对允许插接面，非预期相交均为 0。下次同时记录检测盲区，不能把允许面数、世界坐标范围硬复制给别款，也不能把“零检测”当完整 CAD 证明。

### 显示、产品与验收

- **E20 薄面剔除导致像素缺口。** v2 额片边界曾有 14 像素差异，v4 薄颈圈/百叶曾有 11 个内部差异像素。定位具体薄面后保留必要双面，封闭壳仍剔除。下次查触发视角/部件/法线，不能全模型双面或提高容差。
- **E21 隐藏面与可见面混淆。** 顶冠、开口和关节可能在侧背/仰视暴露，不能按正面判断隐藏。实际保留开放内壁，并对省略的 12 个颈底盖真实补回作比较。下次删面依据包含当前姿态和相机范围；动姿态后旧删面结论失效。
- **E22 诊断画面变成多余浏览页。** 完整装备、无装备、头部三页曾直接供用户切换。v5 改为每台一个完整展品，继续旋转，诊断仍可离线生成。下次将产品页面和内部检查视图分开定义，不能把“一个视角”误解为不能旋转。
- **E23 技术通过替代外观通过。** 864 组通过没拦住扁头、条形天线或枪盾穿模；“头不单薄”也不是整台认可。下次独立记录比例、体积、装配、显示四项，最终看图后才放行；用户原话按部位/版本登记，历史返工不能倒改为通过。
- **E24 只查手持武器，漏查肩载和收纳装备。** 夏亚扎古初版只给机枪做了相交负例，肩盾后壳／支架和腰挂热能斧没有进入同等级门禁；结果自动检查通过，完整背视仍暴露盾背空洞和连接表达不足。后续把肩载护盾、腰挂／背挂武器都视作完整装备：独立记录面范围，分别检查本体相交和受控错误输入，并用背面、侧面近景确认实体后壳及挂点连续。孤立附件图只能核形，不能替代装配验收。

## 后续一台模型的实际交付顺序

1. 从 [制作卡](../skills/reference-model-workshop/assets/model-card.md) 建本款记录，写型号、参考用途、产品单展品、姿态、预算与未知项；查看 RX-78 最终图和相关部件实现。
2. G0/G1 锁资料；G2 建本款比例表、截面/空区、关节层级和装备接口。关键侧面资料不足先补资料。
3. G3 做目标站姿无装备灰模并核对整体体积；G4 单独完成头脸与天线，再回看全身；每步保存实际图和结论。
4. G5 完成胸甲、四肢、凹槽/内壁和枪盾装配；先通过装备相交与接地，再完成全装正斜侧背和关节近景复验。
5. G6 用最终生产资产做原生/低档/全旋转检查，技术回归与人工读图分开；所有必修缺陷清零再交付，不把粗模交给用户负责找错。
6. G7 按已有授权构建/加载/烧录，确认实际版本；用户反馈退回受影响节点。新型号重新估计自己的参数，不复刻 RX-78 五轮时间顺序和错误。
