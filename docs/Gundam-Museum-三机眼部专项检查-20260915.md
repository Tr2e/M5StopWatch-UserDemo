# RX-78、ν 高达与沙扎比眼部专项检查

## 范围与状态

用户要求“同样检查下rx78和牛高达；另外，沙扎比的眼睛是不是也有问题，黑色区域怎么感觉像一条缝隙一样；以上遇到的问题，提炼成经验放到pipeline”。本轮按检查及经验整理执行：**不改模型、不提交、不烧录**。检查基线为 `2822bb7`，沿用用户已认可的 RX-78 SD 比例/站姿、BB387 ν 高达、SDEX017 沙扎比；不把新眼窝代码自动套给全部机体。

本轮结论是问题审查，不是修复验收。实际查看各台当前生产网格的头部正/斜/侧结构图、原生头部图；另查看沙扎比全部11张原生诊断帧（含完整装备100%和65%、正背两侧、灰模及俯视）。生成的48帧转台归档供复核，**没有把全部转台逐帧审阅写成本轮已完成项**。身体和装备不做新一轮美术验收。

## 逐台结论

| 机体 | 代码与画面证据 | 结论与后续修复约束 |
| --- | --- | --- |
| RX-78 | `rx78.cpp` 的 B2 红底、黑色 `face`、金色 `cover` 逐层向前；没有眼眶口沿→内壁→镜片的连续凹腔。正面镜片下缘有明显黑红平面边框；斜面仍读作附在黑底上的金色片。眉檐和颊框遮挡较好，整体并非旧版凸出的整块面罩。 | **同类结构缺口存在，贴片感相对较轻。** 不能因为整脸位于眉檐后就认定眼窝成立。若修复，保留用户喜欢的五边形大眼、金色、红色眼间区域及已认可脸型，仅改变凹腔和连接；不要强行换成命运的四边形轮廓。 |
| ν 高达 BB387 | `nu_gundam.cpp` 黑底 `cover(...,.03,black)` 之外又叠绿色 `cover(...,.008,green)`；内角源坐标黑底z约.430、镜片z约.441，彩片向前而不是退向眼窝内部。侧面绿色片仍可见且凸在黑边前，双斜的立体内壁缺失。 | **同类贴片问题更直观。** 保留当前宽眼轮廓、绿色及BB387头脸比例，重做凹腔，不缩眼、不重做整头。上述两组坐标并非同一XY采样点的精确深度差，不能当实测退入量。 |
| 沙扎比 SDEX017 | `sazabi.cpp` 黑色区由眉檐每侧6段条带组成：每段下缘直接取上缘y−.037、z+.005；没有完整黑眼腔内壁/后壁。中央眉檐y=2.43、z=.55；绿色圆片前端中心y=2.410、z=.577，反而比中央眉檐靠前.027。 | **“一条缝”判断成立，且单眼也未真正嵌入。** 这不是仅调亮黑色就能解决。应按本款参考恢复中央容纳单眼、两侧斜向延伸且宽度变化的窗口，建立口沿/内壁/后壁与单眼支撑，镜片退在窗口内部，保持已补好的头颈、面具支撑链。不能改成扎古水平眼带，也不能套双眼大眼比例阈值。 |

共同根因：把“整张脸藏在头盔前缘后”误当作“眼睛嵌在眼窝内”；前者是头脸装配，后者是眼窝局部拓扑，两者须独立验收。代码里名字叫 `inset`、`eye slit` 或注释写“recessed”，不能代替可见内壁、真实连接和遮挡检查。

## 沙扎比参考核实

重新打开并实际查看 [万代官方 SDEX017 商品页](https://www.bandaispirits.co.jp/products/search/detail.php?grp_id=5325&prd_id=4573102609298000) 的 [斜前商品图](https://bandai-a.akamaihd.net/bc/img/model/b/1000153102_1.jpg)、[背视图](https://bandai-a.akamaihd.net/bc/img/model/b/1000153102_2.jpg) 和 [较正面的商品图](https://bandai-a.akamaihd.net/bc/img/model/b/1000153102_3.jpg)。文本工具未能加载图片，使用浏览器直接显示原官方图片完成核对；未将参考图复制入仓库。

正/斜前图支持：这款有斜向黑眼窗，中央绿色单眼位于有包围边界的暗区；不是两条严格等厚的V字线与凸起亮点。**斜眼窗本身不是错误**，当前模型的问题是将窗口简化为等厚色带及向前放置单眼。官方整机照片支持轮廓与前后关系的定性判断，不足以给出毫米级深度或精确放大倍数；后续改模应补同款头脸近照/拆件，不臆造精确尺寸。背视图不用于量眼窗。

源码黑带垂直高度.037、眼片前端直径.050，已经提示中央窗口容纳关系不合理；它们是模型单位，不是官方测量值。源码证明是实画黑面，不应直接把用户说的“缝隙”理解成网格漏洞。主机原生100%/65%图均表现为黑细线加小绿点，低档会进一步弱化眼区层次，但不能据此推断真机FPS或显示测量。
