# R12 二次 CR：视觉、遮挡与渲染优化

接 R11 逻辑修正 `63a59c8`。把生产 GarageRenderer / RaceRenderer 原样编译到主机像素接收器，使用仓库内 M5GFX Font0 字模，生成带 466×466 圆形遮罩的截图并人工查看。接收器不模拟 AMOLED 色彩、DMA、真机耗时或全部字体排版细节，不能替代设备验收。

## 第一轮自审与修正

- P1：LAP / 名次文字、速度与增压条超出圆屏边缘。移入半径 225 px 安全区。
- P1：赛道只有线条，所谓“上层最后画”未遮住下层；比赛只采样前方约 32 m，另一分支可能根本没画。改为缓存完整 96 段赛道，浅色桥面填充、相机深度排序，保留外侧手绘线框护栏。
- P1：车辆全部画在道路后，会透过桥面。新增近面/视口凸多边形裁剪，以及基于逆深度的线段可见区间裁剪，按真实透视深度处理桥上/桥下。
- P2：赛道预览两端被圆屏截掉。调整绕场镜头距离与高度。
- P2：深色车身也画成纸白，轮圈配色未使用。展示页增加车壳薄色块与条纹，恢复白蓝、白红、深灰红与轮圈色的差异；比赛仍使用轻量线框。
- P2：轮胎相位采用总时间乘当前速度，变速时不连续；车辆斜坡悬浮且未贴合路面。改为累计行驶距离 / 半径，车身基底与路面一致。
- P2：套圈车按累计距离剔除，近处车辆也会消失。可见性与绘制顺序改用相机空间；排名仍用累计进度。
- P2：检查页残留开发占位文案。显示摇杆状态、按钮 GPIO 配置、校准进度和错误提示；被动按钮不谎称物理连接可检测。
- P2：逐笔直绘屏幕存在闪烁风险。复用 HAL 已有 PSRAM 离屏画布，每帧只提交一次，无新增全屏缓冲。

## 第二轮自审与修正

- 低画质保留车身与尾翼轮廓，不再随机删主体线；只减少小机械细节。
- 暂停/发车/结算不画速度线；运行时速度线连续向外运动，不再随机跳位置。
- 撞墙警示先于 HUD 绘制；单人发车显示 SOLO RUN。
- 结算使用插值后的冲线时间；完赛对手退出赛道画面，避免终点叠车。
- 轮圈色不再误染展示车尾翼支架，支架保持石墨色。
- 遮挡缓存放在渲染器成员中，绘制路径为定长数组，无逐帧堆申请。
- Xtensa 反汇编发现临时车型网格占用约 4 KiB 栈，主任务总栈仅 8 KiB。新增原地生成 API：`GarageRenderer::showcaseMesh` 栈帧由 4080 降为 48 bytes；`RaceRenderer::open` 由 4720 降为 736 bytes。
- 路面绘制单函数栈帧 1136 bytes，投影裁剪 480 bytes。这是编译器栈帧检查，不是运行时栈水位。

## 验证与资源

- ASan/UBSan：11 游戏 + 15 Vector Run + Launcher，共 27 套通过，含 64 组确定性比赛。
- 新增生产渲染测试：页面文字四角在安全圆内、暂停像素冻结、四车主色/轮圈色、正反面遮挡一致、近处线不被远桥吞掉、部分遮挡保留两端。
- 8000 组三角形随机近面/视口裁剪；96 个闭环观察位置覆盖 Medium/Low 与套圈；16 个赛道预览方向。
- 原地网格与返回值 API 逐线一致，短缓冲与空指针容量保护通过。
- 主机缓存大小：GarageRenderer 7040、RaceRenderer 28104 bytes。增加固定存储以正确处理遮挡；实际 FPS 仍须真机测量。
- ESP-IDF 构建通过：镜像 `0x499e00`，剩余 `0x56200`（7%）；相对 R0 增量约 115.09 KiB，低于 180 KiB 预警线。
