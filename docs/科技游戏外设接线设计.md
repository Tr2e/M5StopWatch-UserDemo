# 科技游戏外设接线设计

> 目标设备：M5Stack StopWatch（C152）
>
> 外设：Unit Joystick2（U024-V2）+ Unit Dual Button（U025）
>
> 范围：本文只定义电气连接、线束制作与安全验收；软件初始化、I2C 驱动和游戏按键映射另行讨论。

## 1. 结论

使用一根完整 Grove 4P 线连接 Joystick2，并将另一根 Grove 4P 线改造给 Dual Button：

- Joystick2 完整占用 StopWatch 的 PORT.A，使用 I2C。
- Dual Button 与 PORT.A **只共享 5V 和 GND**。
- Dual Button 的两个信号线单独接到后背扩展接口的 GPIO3、GPIO4。

该方案不使用 Grove Y Cable 或 Unit Hub。它避免将 Dual Button 的 GPIO 信号并联到 Joystick2 的 I2C SDA/SCL 上。

## 2. 器材

- StopWatch（C152）
- Unit Joystick2（U024-V2）
- Unit Dual Button（U025）
- 1 根完整的 HY2.0-4P Grove 线（建议 10 cm）
- 1 根 HY2.0-4P Grove 线，用于剪断一端并改造
- 2 根单针杜邦公头，或 1 组 1×2、2.54 mm 杜邦公头
- 热缩管（小径套单个焊点、大径套整个分叉）
- 焊锡、烙铁、剥线钳和万用表

后背扩展接口为 2.54 mm 排母；GPIO3、GPIO4 在右侧排母相邻，可插入 1×2 杜邦公头。

## 3. 接线定义

### 3.1 StopWatch PORT.A

| Grove 线色 | PORT.A 信号 | 用途 |
| --- | --- | --- |
| 黑 | GND | 两个 Unit 的公共地 |
| 红 | 5V | 两个 Unit 的供电 |
| 黄 | GPIO10 | Joystick2 I2C SDA |
| 白 | GPIO11 | Joystick2 I2C SCL |

### 3.2 后背扩展接口

| 后背位置 | 信号 | 连接目标 |
| --- | --- | --- |
| 右侧排母顶部第 1 孔（逻辑针脚 2） | GPIO3 | Dual Button 黄线 / 红键 |
| 右侧排母顶部第 2 孔（逻辑针脚 4） | GPIO4 | Dual Button 白线 / 蓝键 |

Dual Button 的黑线已经经 PORT.A 与主机共地，故不需要再从后背连接 GND。

## 4. 最终拓扑

```text
                    完整 Grove 4P 线
StopWatch PORT.A ─────────────────────────── Joystick2
   黑 GND ────────────────────────────────── 黑 GND
   红 5V  ────────────────────────────────── 红 5V
   黄 GPIO10 / I2C SDA ────────────────────── 黄 SDA
   白 GPIO11 / I2C SCL ────────────────────── 白 SCL
       │
       └─ 黑、红线各做一个绝缘 T 型焊点
          │
          │  改造 Grove 线（保留连接 Dual Button 的 Grove 插头）
          ├─ 黑 ──────────────────────────── Dual Button 黑 GND
          ├─ 红 ──────────────────────────── Dual Button 红 5V
          ├─ 黄 ── 杜邦公头 ─ 后背 GPIO3 ─── Dual Button 红键
          └─ 白 ── 杜邦公头 ─ 后背 GPIO4 ─── Dual Button 蓝键
```

## 5. 线束制作

1. 用完整 Grove 线将 StopWatch PORT.A 直接连接到 Joystick2；该线四芯均保持原样。
2. 将第二根 Grove 线的一端剪掉，保留另一端的 Grove 插头连接 Dual Button。
3. 剪断端的黑线焊接到 Joystick2 连接线的黑线，红线焊接到红线，形成两个独立的 T 型分支。
4. 剪断端的黄线压接或焊接单针杜邦公头，插入后背 GPIO3；白线同样接到 GPIO4。
5. 每个焊点先独立套热缩管；完成后再以大热缩管或可靠的绝缘固定件包覆整个分叉区。
6. 不连接后背 `BAT` 针脚。该针脚是外部 5V 输入，不是可取用的 5V 输出。

## 6. 电气约束与风险控制

- 红线仅连接红线（5V）；黑线仅连接黑线（GND）。严禁红黑短路。
- PORT.A 黄、白只连接 Joystick2，不得连接 Dual Button 的黄、白。
- Dual Button 黄、白只连接 GPIO3、GPIO4，不得回接 PORT.A。
- 后背 `3V3_L2` 不能代替 Unit 的 5V 供电。
- Joystick2 的 I2C 信号和 Dual Button 按键输出均为 3.3V 逻辑；本设计不将 5V 施加到 ESP32-S3 GPIO。
- Joystick2 带有 WS2812 RGB LED。首次通电和续航测试时保持 LED 关闭或低亮度，确认外设 5V 供电稳定后再提升亮度。
- 所有剪线、焊接和插拔操作必须在 StopWatch 关机且 USB 已拔除时进行。

## 7. 通电前验收

在未连接 USB、未开机状态下，使用万用表完成以下检查：

- [ ] PORT.A 红线与黑线之间无短路。
- [ ] Dual Button 黑线与 PORT.A 黑线导通。
- [ ] Dual Button 红线与 PORT.A 红线导通。
- [ ] Dual Button 黄线与后背 GPIO3 导通。
- [ ] Dual Button 白线与后背 GPIO4 导通。
- [ ] Dual Button 黄、白均不与 PORT.A 黄、白导通。
- [ ] 所有焊点无裸露导体，杜邦头插入方向与后背丝印一致。

首次上电后，再确认：

- [ ] PORT.A 红黑之间为约 5V。
- [ ] Joystick2 与 Dual Button 无异常发热、异味或反复重启现象。
- [ ] 未按下 Dual Button 时，两根按键信号为稳定高电平；按下时对应信号为低电平。

出现异常发热、异味、显示反复重启或 5V 明显异常时，应立即断开 USB/关机，检查红黑线与所有焊点，禁止继续通电。
