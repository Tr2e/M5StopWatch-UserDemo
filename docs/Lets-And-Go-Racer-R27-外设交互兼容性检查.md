# R27 外设交互兼容性检查

日期：2026-09-09。范围：R27 新首页、选择流程、比赛 HUD、暂停及结算，与 Joystick2 + Dual Button 的兼容性。设备在场，但本轮未接外设电气部分；下文区分代码与主机证据、目标构建和真实外设验收。

## 结论与输入模式

后续第八批更新：结算页已支持摇杆上下选择（保留左右兼容），并允许外设模式直接触控 RETRY / GARAGE / EXIT。以下“触屏直达仅机身模式”的历史描述不再适用于结算页；驾驶输入源仍保持互斥。详见 R27 UI 记录第八批。

新 UI 保留完整外设操作路径。外设和机身模式共用游戏状态与渲染器，分别消费输入；新增触屏 NEXT 和结算直达操作只在机身模式执行，不改变红蓝键语义。

进入 Racer 后自动探测外设并进行静止校准；连接完成后进入选车。若在检查/校准页点击 PLAY ON DEVICE 或按机身 B，则停止外设 Provider、关闭 Grove 供电并进入机身模式。晚间接回 Joystick2 + Dual Button 后，需要退出并重新打开 Racer，等待检测和校准。游戏中不做热插拔自动切换；机身 A+B 退出在外设模式也可用。

## 逐页操作矩阵

| 页面 | Joystick2 | Dual Button | 与新 UI 的关系 |
| --- | --- | --- | --- |
| 检查/校准 | 保持回中，等待自动完成 | 红蓝同时按住 800ms 退出 | PLAY ON DEVICE 只选择机身模式；被动按钮显示 CONFIGURED 不代表实体已连接 |
| 选车 | X 左右换车，Y 切换视角；主轴锁避免斜拨双动作 | 蓝短按确认；红短按/长按返回检查页 | SELECT 对应蓝键；退出使用双键组合 |
| 车型确认动画 | 不导航 | 红键返回；双键退出 | 动画结束自动进入对手页 |
| 对手 | X 浏览七名候选及 READY，跳过玩家车型 | 蓝短按添加/移除；READY 上蓝短按继续；红短按在已选对手上移除，否则返回选车；红长按直接返回选车 | 固定 NEXT 是机身触屏入口；外设保留 READY 项。支持 0～2 对手；补充蓝键提示 |
| 赛道 | X 切换两条赛道 | 蓝短按开赛；红键返回对手 | START RACE 对应蓝键 |
| 发车/倒计时 | 不导航；连续操纵状态仍采样 | 双键退出 | 数字改版不改变计时和起跑流程 |
| 比赛 | X 实时转向，Y 不参与驾驶 | 红按住刹车，蓝按住增压；红长按约 500ms 暂停；双键退出 | 自动油门；机身模式的触屏转向和顶部暂停不混入外设操纵 |
| 暂停 | 不导航 | 松开后再次长按红键继续，要求输入有效；双键退出 | 提示 HOLD RED WHEN INPUT READY；不是蓝键继续 |
| 结算 | X 左右切换 RETRY / GARAGE / EXIT | 蓝短按执行；红键回车库；双键退出 | 三行结果按钮仍支持摇杆焦点选择；直接点某行只用于机身模式 |

红长按暂停会与持续刹车共享同一按键，这是原有映射，本轮没有重新分配。Joystick2 自带按压未映射新动作。

## 本轮发现并修复

1. **外设缺少首帧显示与按键释放门禁。** 原 Provider 切页清理缓存和摇杆回中状态，但没有拦截跨页按住后松开的蓝键，也允许首帧绘制期间的新事件进入下一页。新增生产使用的 `RacerScreenInput`：页面显示后释放红蓝键、摇杆回中，再接受新的菜单/暂停动作；连续转向、刹车与增压保持最新状态。
2. **校准完成帧可能消费旧确认。** App 先取输入，再因校准完成切到选车，随后会把旧蓝键交给选车页。自动转页后清理该样本中的普通操作，保留退出，避免车库尚未显示就确认车型。
3. **切页清空可能吞掉异步退出。** 外设队列和机身队列都在普通切页时保留尚未消费的全局退出；只有关闭/重新打开才完全清空。退出不受轴失效或首帧门禁限制。
4. **对手页蓝键提示不足。** 外设底栏补为 L/R / BLUE SELECT，READY 仍显示 BLUE: NEXT。首轮画面回归发现较长提示越过圆屏安全边界，已缩短并重跑验证。

RivalSelect 与 TrackSelect 都使用 Horizontal 导航模式；每次切页仍强制重新回中，不因模式值相同而保留旧方向。重复送屏不会清空当前页面尚未消费的合法短按。

## 完整调用链检查

| 检查项 | 当前代码结论 / 验证边界 |
| --- | --- |
| 资源与供电 | 进入时停止 LVGL 并等待在途读取，检查 Grove 5V 开启结果、等待 20ms，再打开外设。机身模式选择和退出均先停止 Provider，再关电 |
| 接线隔离 | Joystick2 使用 I²C1 GPIO10/11；Dual Button 使用 GPIO3/4；机身 A/B 使用 GPIO2/1。触屏有独立读取任务，触屏读取失败不会改变外设 `RacerInput.valid` |
| 采样与慢帧 | 外设 GPIO/菜单事件任务每 10ms，轴 I²C 任务每 20ms。RGB 仅发布目标，由轴任务写总线。短按/短拨锁存至消费，连续量取最新；同类重复事件允许合并 |
| 校准与健康 | 使用 esp_timer 时钟；至少 700ms、20 个独立样本、XY 稳定行程要求。300ms 过期或连续 3 次错误失效；轴故障不会吞掉有效按钮的返回/退出 |
| 比赛失联 | 物理层中性转向、禁增压并刹车；App 观察到无效持续 600ms 后暂停。恢复需输入有效和新的红长按，不会自动恢复 |
| 退出与重入 | 等待机身任务和外设任务退出后销毁对象，释放 GPIO/I²C、关闭电源、恢复 LVGL；音频先同步关闭。主机重置/控制逻辑已覆盖，电气重入待实测 |
| 剩余工程边界 | Provider 诊断日志仍在采样互斥范围内；任务创建失败回退逐帧采样，日志会报告降级；任务退出等待尚无超时上限。总线超时、日志阻塞、任务失败与关闭卡住场景不能由本轮纯逻辑测试证明消除 |

本轮修改限于 Racer 输入上下文、App 转页处理、外设 UI 提示与回归；没有修改共享 Joystick2 / Dual Button 驱动、赛道、车辆或音乐。
