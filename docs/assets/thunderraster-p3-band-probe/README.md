# ThunderRaster P3-0：RX-78 行带容量探针

日期：2026-09-24

设备：StopWatch ESP32-S3 rev 0.2，`/dev/cu.usbmodem83301`

分支：`perf/thunderraster-rx60-p3`

配置：RX-78 60% 专用三轮固件，额外开启 `STOPWATCH_RX_BAND_PROBE=ON`。

## 结果

| 行带 | 平均成员 | 平均额外成员 | 平均跨带图元 | 奇/偶成员 | 奇/偶扫描行 | 峰值活跃 | 峰值边界存活 |

| 16 | 2,839.0 | 920.0 | 848 | 1,458.7 / 1,380.0 | 8,895.3 / 8,414.3 | 392 | 158 |

行带成员数包含图元跨带产生的重复 membership，但不重复投影或模型分类。`max_carry × 12 B` 仅表示沿用当前紧凑命令时的边界存活载荷下界；如果改成持久化完整 triangle setup，真实状态会更大，因此首个原型不复制 setup 状态，而以唯一命令流 + 16-bit band index 回放。

三轮探针帧间隔为 `56.144 / 56.160 / 56.147 ms`，panel prepare 为 `12.035 / 12.021 / 12.031 ms`。与无探针分支零点 `50.301 ms`、panel prepare `6.402 ms` 相比，统计开销约 `5.62 ms`，不能把 17.8 FPS 当成候选性能。光栅本体仍为 main `28.862–28.887 ms`、worker `28.531–28.546 ms`，说明探针没有改变像素内核负载。

诊断 BIN 为 `0x463db0`（4,603,312 B），应用分区余 `0x8c250`（11%）；写后 hash 校验通过。完整主机门禁再次通过：60/65/90/100 framebuffer 共 1,408 组一致。

筛选串口证据见 [`band-probe.log`](band-probe.log)。
