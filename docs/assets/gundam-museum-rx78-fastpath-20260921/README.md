# RX-78 无损 fast path 真机证据（2026-09-21）

硬件：ESP32-S3，240 MHz，8 MiB 80 MHz Octal PSRAM，CO5300 468×466 framebuffer 面板。  
基线 commit：`ffc6717`；测试分支：`feat/gundam-arena`。  
每个真机 A/B 档位交错运行 24 帧，姿态序列相同；65% 和 100% 分开统计。

## 接受项

### Solid scanline span + trusted depth

实体三角形逐行用原重心公式确认左右边界，保证内部覆盖后省略重复 coverage 判断；三角形级验证逆深度范围后，内部像素省略有限值、正值和 clamp 检查。

| --- | ---: | ---: | ---: | ---: |
| 65% | 88.187 ms | 85.166 ms | 150.463 ms | 147.260 ms |
| 100% | 142.947 ms | 132.828 ms | 205.211 ms | 194.822 ms |

结论：raster 分别降低 3.4%/7.1%，整帧 draw 分别降低 2.1%/5.1%。

### Native framebuffer composite

为 CPU 可寻址 framebuffer 增加可选行访问与脏区标记接口。仅在 RGB565、rotation 0、完整 clip 和真实 framebuffer 均成立时，光栅器直接合成到 framebuffer 行；其他设备和布局回退原 span API。面板存储为 byte-swapped RGB565，写入前显式转换。

### Framebuffer span transaction

在 native framebuffer 路径出现前，受保护的 `startWrite/endWrite + setAddrWindow/writePixels` 使 blit 稳定减少约 1.1–1.2 ms，总 draw 改善约 0.7–0.8%。保留为 native 条件不满足时的回退优化。

### Sparse depth clear

RX-78 最终只占活动深度平面的约 17.8%。光栅器现在可接收调用方提供的占用 bitset；下一帧只清零上帧实际非零的深度项，而不是向整个 PSRAM 深度平面写零。存储是显式可选的，Museum 提供约 22 KiB，其他共享光栅器实例不增加大块工作集。Nu 的 65% 隐藏线会原地扩展深度布局，因此保持原始完整清理。

| 100% | 28.781 ms | 22.086 ms | 178.608 ms | 176.054 ms | 11.771 ms |

### RX-78 双核行分区光栅

将已投影、已裁剪的 RX-78 面片按原始顺序保存一次，两个 CPU 核分别处理互不重叠的上下行区间。分界行对齐到稀疏占用 bitset 的字节边界，因此颜色、深度和占用记录都没有跨核写冲突；每个分区仍严格遵守原面片顺序和等深覆盖语义。CPU1 使用随 renderer 生命周期创建的常驻 worker，退出 Museum 时同步停止并回收。

### 房间绘制与几何准备重叠

细分计时显示 65% 的 background/room/depth-clear/cull 分别约为 12.99/5.08/2.15/4.15 ms。常驻 CPU1 worker 先绘制房间，CPU0 同时清理离屏深度、剔除并准备面片；房间任务完成后，同一个 worker 再处理下半屏光栅，framebuffer composite 始终等待房间结束，因此绘制顺序确定。

共享 PSRAM 争用使并行 room work 自身增至约 8.3 ms，深度清理与准备也略有变慢，但 wall time 仍改善：65% draw 从 106.390 降至 104.999 ms，含 present 周期 116.757 ms（约 8.57 FPS）；100% draw 从 140.426 降至 138.794 ms，周期 150.521 ms（约 6.64 FPS）。这证明非重叠任务并行有效，同时也把共享内存带宽确定为后续框架优化的核心约束。

## 否决项

- 交错 `[depth16|color16]`：100% blit 29.72→23.84 ms，但 32-bit 清屏抵消收益；65% draw 143.25→151.63 ms，100% 194.58→199.69 ms。
- 最近邻重复行缓存：bitset 扫描和分支抵消读取节省，真机无稳定收益。
- 直接重关联深度平面：6,720-case 中出现 1 个 framebuffer 像素差，否决。
- 带量化边界回退的深度平面：6,720-case 精确一致，但 RX-78 主机 65% 从约 950 µs 退化到 1,062 µs，未刷真机。
- 保守 early-Z 深度平面：像素一致，但真机 raster 在 65%/100% 分别慢 4.7%/5.6%。
- 8-bit 索引色平面：110 色、无溢出，但 65% draw 150.114→154.953 ms，100% 188.431→202.495 ms。
- 无像素中心面片跳过：整屏哈希一致；65% draw 125.339→125.047 ms（噪声级），100% 180.248→180.499 ms（略慢）。
- front-to-back 中心深度排序：首个 RX-78 姿态改变 88 像素；部件级排序改变 14 像素；加入严格深度区间约束仍改变 4 个 Q13 等深边界像素，全部回退。
- 4-bit 片内粗深度：完整 88 KiB 在正常 App 创建后的最大连续 internal block（69,632 B）下无法分配；缩为 65% 专用约 37 KiB 后可分配且哈希一致，但 65% draw 124.299→129.623 ms，回退。
- 2% 量化边界回退深度平面：6,720-case 与真机哈希一致，但 65% raster 83.361→85.570 ms、100% 131.240→136.891 ms，回退。
- 稀疏 framebuffer 背景恢复：使用上一帧模型占用位图恢复模型像素，并以背景色重画旧房间线；哈希仍为 `2718444083`，但零散写使 65%/100% background 从约 12.4 ms 增至 23.9/39.7 ms，draw 增至 116.1/166.1 ms，回退。
- 65% 半屏 internal-RAM 深度：在创建 CPU1 worker 前成功分配 76,176 B 连续内部内存，将 276×138 下半屏深度随机读写留在片内；24 姿态 A/B 的整屏哈希完全一致。worker 从 50.625 ms 降至 49.538 ms（约 1.09 ms），但将深度连续回写 PSRAM 需要 2.012 ms，`project_raster` 从 70.204 ms 增至 71.447 ms。继续尝试不回写、合成时直接读取占用 bitset，虽保持哈希一致，却使当时的逐目标像素位测试合成明显变慢（候选 `blit` 18.961 ms；原生深度连续读取基线约 15 ms）。该“镜像+回写”实现完整回退；后续 sparse composite 改为由置位源像素驱动后不再读取深度，使无回写的权威深度带重新具备净收益，见下文。
- 逐行占用范围清理：记录每行首末占用，将下一帧逐置位深度清零改为连续跨度清零。96+96 帧真机 A/B 哈希一致，`depth clear` 4.563→1.864 ms，但记录边界使 raster 56.183→56.956 ms，最终 draw 86.541→86.436 ms，仅快 0.105 ms 且增加约 1.7 KiB 常驻状态，按收益门槛回退。
- 稀疏合成源行复用：将同一 65% 源行只解码一次，生成目标 span 后 memcpy 到 1–2 个目标行；48 姿态哈希一致，但候选 `blit` 9.365 ms 与已接受实现的 9.383 ms 等价，同时增加约 3.4 KiB 栈临时量和 span 复杂度，完整回退。A/B 参考值 11.141 ms 是实验中移除 `destinationLast` 缓存污染热循环所致，不作为生产基线。
- 双核光栅非对称分区：针对 65% 模型分辨率扫描 44%/46%/48%/50% 上半区，24 姿态整屏哈希全部一致；`project+raster` 分别为 70.183/67.489/66.159/64.385 ms，draw 分别为 106.403/99.560/98.255/96.409 ms。50% 仍明确最优，结合此前 60%/70% 更慢的数据，说明两个核心的行工作量已基本对称；保持生产代码固定等分，移除诊断开关。
- 可见共享顶点并行投影：阶段分解先测得面片准备 19.606 ms、上下半屏光栅 42.879/44.542 ms。让 CPU1 完成房间后与 CPU0 各投影一半可见共享顶点，投影墙钟时间仅 2.489 ms，但标记、源索引和新增 32 KiB PSRAM 工作集使完整面片准备反增至 20.819 ms；draw 98.021→99.213 ms，完整回退。结论是当前 19.6 ms 主要不是顶点变换，不能以扩大冷数据换取其并行化。
- 导航 overlay 原生 framebuffer 直写：按 M5GFX 同样的 Bresenham 覆盖规则直写两个箭头，48 姿态整屏哈希一致，但 overlay 仅 122→96 µs、draw 86.992→86.964 ms，只省 28 µs。不为如此小的收益保留重复线段内核，仅保留 `overlay_us` 指标。

### 无回写的片内权威深度带

65% 双核路径把 276×138 下半屏深度直接保存在 76,176 B 片内 RAM 中。当前 sparse composite 只消费占用位图和颜色，不再需要完整深度平面，因此片内带可以成为下半屏唯一权威深度存储。清理、光栅、诊断读取和通用合成均按行选择正确平面；跨越分界线的单核回退自动拆成上下两个互不重叠的裁剪区间。

为同时容纳热点投影坐标，`open()` 先完成默认 RX-78 顶点索引并申请精确的 32,088 B 投影前缀，再申请 76,176 B 深度带和较小控制表，避免小块分配先造成连续空间碎片。48 姿态交错 A/B 整屏哈希 0 差异：

| 路径 | depth clear | project+raster | CPU0 raster | CPU1 raster | draw | blit | present |

| 统一 PSRAM 深度 | 19.442 ms | 56.035 ms | 41.387 ms | 41.435 ms | 88.254 ms | 8.169 ms | 11.777 ms |
| 片内权威深度带 | 17.507 ms | 55.638 ms | 41.156 ms | 40.783 ms | 86.472 ms | 8.162 ms | 11.746 ms |

draw 减少 1.782 ms，其中深度清理减少 1.935 ms，CPU1 光栅减少 0.652 ms；两个片内热点缓冲同时生效。试验后内部 RAM 仍余 55,919 B，最大连续块 31,744 B，分配失败时自动回退统一 PSRAM 深度平面。
