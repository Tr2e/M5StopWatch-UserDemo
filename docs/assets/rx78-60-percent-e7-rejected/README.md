# RX-78 Benchmark 60% E7：quad 扫描行递增插值（否定）

日期：2026-09-24

## 候选与表面结果

候选让 solid-quad 每条扫描行只在首像素按原公式计算重心坐标，后续像素递增 `s/t`。主机既有 1,408 组最终 framebuffer 对比通过；真机三轮 60% 为 `50.122 / 50.099 / 50.130 ms`，相对 E6 均值表面降低约 0.724 ms。100% 三轮为 `83.853 / 83.853 / 83.826 ms`，表面降低约 1.84 ms。

## 否定原因

新增 256 组确定性 skew-quad 门禁，同时比较旧三角路径与 quad 特化的 RGB565、逐像素 Q13 depth 和 occupancy。递增候选出现内部 depth 不一致；虽然现有 RX 姿态的最终颜色未变化，但该误差可能在未覆盖的遮挡组合中改变后续深度胜负，因此不能用“当前画面相同”替代深度语义。

候选内核已撤回；更严格的颜色+深度回归保留。撤回后 sanitizer 与完整 1,408 组 framebuffer 门禁重新通过。
