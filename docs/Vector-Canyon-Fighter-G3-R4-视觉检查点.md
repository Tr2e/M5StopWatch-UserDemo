# Vector Canyon Fighter · G3-R4 视觉检查点

## 结论

R4 视觉部分于 2026-09-01 经 StopWatch 实机迭代后阶段性通过并提交检查点。

本检查点确认战机、HUD 布局、HUD 信息密度和主配色方向；高速/BOOST 连续性仍属于 R4 后半段，尚未宣告完成。

## 战机

- 采用原创第三人称线框战机，不复刻参考作品的具体模型。
- 几何升级为 50 个顶点、78 条结构边。
- 明确包含长机鼻、座舱、四片分离机翼、四个发动机舱、双垂尾和四个翼尖武器杆。
- 四个发动机分别绘制尾焰，BOOST 时同步延长。
- 冷白主轮廓、暗蓝内部结构、青色座舱与暖色尾焰保持语义分离。

## HUD

HUD 参考航空平显的信息层级，但只显示游戏模型中真实存在的状态：

- 顶部航向数值和航向刻度；
- 滚转弧与动态指针；
- 随滚转旋转、随俯仰位移的五级俯仰梯；
- 飞行路径圆环与固定机体基准；
- 速度/高度主次刻度、数值窗和动态游标；
- 航迹偏差尺；
- 输入、推进、滚转和俯仰状态；
- 事件触发的地形与撞击告警。

新增 `heading` 飞行状态，由转向输入连续积分并归一化到 0–359°，避免 HUD 使用无来源随机数值。

## 配色令牌

配色遵循 `docs/tech-ui-design-guidelines` 的语义约束，并采用项目中已有的科技色：

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 地形主结构 | `#FF6A33` | 近景峡谷与主轮廓 |
| 地形中/远景 | 降亮度橙 | 透视层级 |
| HUD 主状态 | `#00FF66` | 主读数、主刻度和姿态符号 |
| HUD 次级状态 | 暗绿 | 次刻度与参考线 |
| 战机轮廓 | 冷白/青 | 与地形、HUD 分离 |
| 尾焰 | 金橙 | 推进反馈 |
| 告警 | 亮黄 | 避免与橙色地形混淆 |
