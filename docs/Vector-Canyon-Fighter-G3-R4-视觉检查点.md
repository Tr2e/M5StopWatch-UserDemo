# Vector Canyon Fighter · G3-R4 视觉检查点

## 结论

R4 视觉部分于 2026-09-01 经 StopWatch 实机迭代后阶段性通过并提交检查点。

本检查点确认战机、HUD 布局、HUD 信息密度和主配色方向；高速/BOOST 连续性仍属于 R4 后半段，尚未宣告完成。

## 战机

- 采用原创第三人称线框战机，不复刻参考作品的具体模型。
- 几何升级为 66 个顶点、114 条结构边。
- 明确包含长机鼻、座舱、四片分离机翼、四个发动机舱、双垂尾和四个翼尖武器杆。
- 四个发动机分别绘制尾焰，BOOST 时同步延长并显示收缩菱形激波环。
- 冷白主轮廓、暗蓝内部结构、青色座舱与暖色尾焰保持语义分离。

## HUD

HUD 参考航空平显的信息层级，但只显示游戏模型中真实存在的状态：

- 顶部航向数值和航向刻度；
- 滚转弧与动态指针；
- 随滚转旋转、随俯仰位移的五级俯仰梯；
- 飞行路径圆环与固定机体基准；
- 速度/高度主次刻度、数值窗和动态游标；
- 航迹偏差尺；
- 输入、推进、滚转和俯仰状态；
- 事件触发的地形与撞击告警。

新增 `heading` 飞行状态，由转向输入连续积分并归一化到 0–359°，避免 HUD 使用无来源随机数值。

## 配色令牌

配色遵循 `docs/tech-ui-design-guidelines` 的语义约束，以暖色环境、冷色仪表和中性机体分离信息角色：

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 地形主结构 | `#FF7138` | 近景峡谷与主轮廓 |
| 地形中/远景 | 降亮度橙 | 透视层级 |
| HUD 主状态 | `#80D8E8` | 主读数、主刻度和姿态符号 |
| HUD 次级状态 | `#275F69` | 次刻度与参考线 |
| HUD 动态游标 | `#E3FBFF` | 航向、航迹与数值游标 |
| 战机轮廓 | `#E9F2F2` | 与地形、HUD 分离 |
| 座舱 | `#58A6D8` | 独立于 HUD 的结构蓝 |

## R4 后半段性能校准

2026-09-01 在 StopWatch 真机完成巡航、持续 BOOST 和姿态输入数据采集：

| 指标 | 初始实现 | 校准后 |
| --- | ---: | ---: |
| 实际帧率 | 约 14.7 FPS | 20.2–20.4 FPS |
| 平均渲染耗时 | 57–58 ms | 38–39 ms |
| 最大渲染耗时 | 59–61 ms | 40–42 ms |
| 每 5 秒模拟截断 | 约 74 次 | 0 次 |
| 持续 BOOST | 仅短脉冲 | 102/102、103/103 活跃帧 |

校准措施：

- 移除独立全屏 sprite 到 AMOLED framebuffer 的重复内存复制，改为在设备 framebuffer 内完成一帧后统一提交；
- 模拟追帧上限由 3 步提高到 5 步，消除全帧传输期间的时间丢失；
- 帧门限由 50 ms 恢复到 33 ms，避免与系统调度周期叠加后额外跳帧；
- `FlightInput` 增加 `boostActive` 保持状态，同时保留 `boostPressed` 一次性事件，方便后续硬件 provider 按输入能力映射。

当前约 20 FPS 是保留 468×466 全帧、37×26 地形网格、完整战机与 HUD 后的实测结果。本轮没有通过删除纵向网格或 HUD 来换取帧率。原计划中的 24 FPS 目标尚未达到，因此 R4 最终 Review 必须同时记录用户对实际运动连续性的视觉判断，不能只凭数据宣告通过。
