## 可执行步骤及退回条件

1. **G1 参考覆盖**：实际查看官方站姿与动作两张、同款实拍正斜背侧、头部近照、说明书、板件和拆件。自检：头壳、脸芯、天线装配和前后关系可解释；缺关键侧面依据则继续补图。产物为私有参考账本与读图结论。
2. **G2 结构计划**：独立重建头壳/面芯、胸腹、裙甲、短上臂/前臂、短腿/踝甲/大脚及武器。自检：按说明书编号对应代码，记录全身/头壳高度、肩头宽、面罩/头宽、眼宽、前后深度与关节锚点。不得引用 HG 的缩放系数。
3. **G3 灰模**：无装备正、斜、两侧、背、俯仰检查后，再装装备。双足同地面，膝/踝和肩/腕连续；自检发现头身失衡、裙甲挡腿或装备遮脸则留在本节点修复。保存内部 G3 源码和同相机基线。
4. **G4 头脸**：隔离头部，正/斜/侧逐项核对眉檐、眼窝、面罩、下巴、颊框、后壳。面芯位于前壳围合的开口内，鼻/面罩不突破眉檐的前缘包络；天线有共用尖顶，厚度也在末端归零。自检三视图后回看全身，任何一面恶化即返工。
5. **G5 精修及结构复验**：平面护甲倒角、真实胸口凹槽、颊排气槽、喷口和可见内壁；按官方涂装分色。对用户站姿做脚底、持枪、持盾连接检查。删面必须有补回新增面且像素一致的证据，不能照搬 HG 的 32 个省略面。保存 CR1 的发现、修复、复验。
6. **G6 生产显示及技术回归**：同源结构图和原生图、65%/90%/100%、全方位及极端俯仰，检查裁剪、深度、局部重画、切换与重入。仅 SD 站姿计算 864 组合；牛/强袭回归与原帧比较。ASan/UBSan、容量/有限坐标/法线、正常构建及证据完整性均须检查。重新打开最终图，不能直接抄上一轮“通过”。保存 CR2 和最终源码哈希。
7. **G7 用户/真机验收**：本轮不自动烧录；交付源码、可构建固件和实际软件渲染。用户外观认可、真机 FPS、余量分别待验，不能由主机测试替代。

每步的最小记录：输入 → 产物 → 实际检查画面 → 发现 → 修改 → 同相机复验 → 状态。后续修改使受影响节点及下游结论失效，必须重查。所有自检由 Codex 执行，不转成逐步许可请求。

## 后续问题进入 Pipeline 的具体规则

- 风格合同先于头身判断：HG 的头大投诉不能直接变成 SD 缩头；SD 仍须有明确套件比例，禁止“大头就行”。
- “透视错误”先查几何：固定相机测眉檐/面芯/颊框的 Z 层次，再检查投影，禁止换取景掩盖凸脸。
- 站姿按关节作刚体旋转：脚底平面保持着地，左右适度不对称，短肢不剪切拉伸；枪与盾随腕/前臂锚点。
- 尖天线检查三维：正面、侧面和低画质均查，不能只把正面轮廓画成三角但保留厚方头。
