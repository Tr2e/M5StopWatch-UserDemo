## G2 比例、姿态与装配合同

坐标约定：Y 向上、Z 向前、X 正为机体左，双脚地面为 y=.025。设计目标是大头、短躯干、厚足的 SDEX 比例；白色主体、蓝胸肩膝、红足／额片／翼缘、黄色 V-fin、绿色眼窗；宽展黑红主翼是第一轮廓识别点。

完整装备采用右手光束步枪、左臂实体盾、背包展开双翼；Arondight 长剑与长炮分别收纳在背包中央两侧。每件附件保留独立面范围，支撑链为：

- 胸背 → 背包插柱 → 背包；背包 → 左／右翼挂轴 → 左／右翼。
- 右前臂 → 腕轴／拳体 → 步枪握把；左前臂 → 盾支架 → 盾背。
- 背包 → 长剑挂架 → 长剑；背包 → 长炮挂架 → 长炮。
- 胸部颈圈 → 颈柱 → 头盔内壳。

阶段顺序：G3 无装备灰模 → G4 头脸和配色身份 → G5 完整装备与严格装配 → G6 原生画面、65% 档、48 帧转台和六机体回归 → G7 固件构建。用户真机验收与主机自检分开记录。

## G3 灰模体积

灰模实际检查正面、正斜、左右侧、背面和俯视。头壳不是强袭统一缩放：独立建立圆深后脑、宽颊框、短胸腰、粗小腿与宽底足。双脚共面接地区域各 **0.3999**；无天线头盔顶／下缘量测得到头身关系 **2.89573**，头深／头宽 **0.983669**。

首轮风险是腕连接在正面投影偏细、眼窗可能因同层覆盖只剩一侧。进入 G4 后用彩色正面和头部三视确认左右眼都稳定可见；腕轴在装配近景继续核对。

## G4 身份关

建立白色外 V-fin、黄色内 V-fin、红额片、绿色额摄像窗与双眼、白色宽颊框和深后脑。彩色正面首次复核发现红下巴识别点不足，补成与面罩相连的实体楔块；没有用贴片悬在脸前。正／斜／侧头部图确认双眼、额片、下巴和天线在连续方位没有跳面。

胸部采用蓝色主甲、白色斜切进气框、黄色内口和红色腹部；肩甲为蓝壳、白前甲和红色小块；腿部保留蓝膝与踝部白色内嵌，不复制强袭胸肩尺寸。

## G5 完整装备与装配自检

初版完整装备的自动相交检查抓到两个真实问题：盾支架末端与盾背只接近未咬合，长剑挂架与剑体之间有小间隙。端点按双方局部挂点重算后，连接面配对为：头颈16、步枪握持8、盾10、双翼各12、长剑20、长炮22。

随后严格附件互检发现长剑／长炮收纳位置穿入左右翼。没有扩大允许白名单，而是把两件武器移至背包中央独立收纳槽。最终步枪、盾、双翼、长剑、长炮对身体及其他附件的非预期相交均为 **0**，拳壳对前臂装甲相交为 **0**。

三个受控负例均按预期失败：头盔上移后头颈接触变0、单翼外移后翼根接触变0、步枪推入胸部后检出141个非预期面配对。该问题已被现有 pipeline 的“完整装备附件互检”和 C10“可见支撑链”覆盖，无需新增同义规则。

## G6 原生显示、旋转与回归

生产渲染器使用固定尺度74；尝试80时在部分旋转角出现242个矩形视口边界像素，76仍有40个，最终74在全装备、三档分辨率、三档俯仰和24方位下圆屏边界与矩形视口边界均为0。没有裁短官方特征翼，也没有做随角度变化的自动缩放。

实际查看了原生完整装备图、头部放大、65%档、结构近景和四页48帧转台。第二轮另放大复核正后、双后斜、左右侧和双前斜共8个关键角度；头、盾、翼和两件背挂武器均保持连续连接，黑翼遮挡随角度连续变化。

- 最终网格 **3156 / 4096** 面，无溢出；共享工作区 **1,274,184 B**。
- 命运高达主机测试864组：内部像素差异0、埋面差异0、局部刷新差异0；剔除差异累计12个边缘像素，单例最多2像素；全装备边界0。
- ASan/UBSan 同一864组通过。
- 六机体分别重跑864组；导航顺序、缓存失效、重新进入和48帧转台均通过。
- 性能 A/B 共6720组逐像素一致。命运高达65%档优化均值 **969.422 µs**、p95 **1371.96 µs**；100%档均值 **1542.33 µs**、p95 **2322.08 µs**。其面数和主机耗时均不高于现有强袭。
