# R19：田宫模块赛道、深色远景与精细缩略图

本轮只改生产渲染、验证和文档。不改中心线、坡度、倾斜、物理宽度、碰撞、赛车模型、输入或三圈规则；继续无中间隔板，既有 figure-eight 立交不是对商品布局的逐尺寸复制。

## 实拍依据与实现

使用 browser 技能直接查看田宫官方商品照片，未下载或把照片打包进固件：

- [JCJC 94892 红／蓝／白赛道](https://www.tamiya.com/japan/products/94892/index.html)：采用其白色直道／桥接模块、红蓝弯道、ABS 实体侧墙与分段接缝。保留用户要求的开放路面，不复制实物中的三条分道墙。
- [69579 白色桥接扩展件](https://www.tamiya.com/japan/products/69579/index.html)：参考其桥面厚度、侧墙轮廓和支撑底座；现有游戏立交高度与路径不变。

选道页与比赛统一深蓝黑远景、低对比远山。赛车选择、展示与结算保留纸色主题。选道预览增大并调整构图，补充墙顶高光、接缝、接地影与桥墩底座。比赛小地图从 32 点线条改为与物理赛道同源的 96 段有宽度色带，按高度排序，标出桥梁边缘和起点；玩家标记最后绘制，重叠时仍可识别。

## 自审一：实际截图与遮挡修复

第一版实体墙出现阶梯缺口：整段 painter 排序会让相邻路面擦掉凸出的墙顶。改为缓存经过视锥裁剪的路面／双侧墙／桥底，通过逐扫描行逆深度测试决定颜色；不再依赖整个赛段的绘制顺序。车辆也使用相同表面遮挡。接缝与高光线通过场景遮挡测试，避免穿过桥体。

第一版小地图逐段绘制落影产生条纹，改为先绘制全部落影，再绘制高度排序的路面。远山从重复尖峰改为低对比连续山脊。自审后人工查看选道、发车、近车、普通弯道、桥上和桥下输出。

## 自审二：边界、平台与资源修复

- 新增小地图定位圈安全边距测试，发现部分弯道离卡片边缘过近；缩放从 2.8 调至 2.6，并下移卡片，避开圈数 HUD。
- 发车、倒计时、暂停及冲线提示改成统一深色面板，消除文字后方零碎浅色块。
- 主机 canvas 宽度返回 `int`，设备库返回 `long`；修正扫描行宽度的模板类型差异，并重新完成 ESP-IDF 构建。
- 遮挡容量按 96 × 6 + 48 = 624 面设置：每段路面／底面两三角形、两侧墙四三角形、48 个棋盘贴花三角形。保留显式越界保护，144 个整圈／画质视角实际最多 442 面。
- 新增深度绘制顺序独立性、背景保留、深色天空／地面、三色缩略图和安全半径断言。保留真实桥底遮挡、满容量保护、近裁剪、三档画质、16 个预览绕看时刻及重复打开／关闭检查。
- 赛车几何、涂装未改；4 张选车及 4 张展示截图与 R18 基线逐像素一致。

## 内存与门禁结果

不新增整屏深度缓冲或逐帧堆分配；深度与颜色暂存只占 466 × (4 + 2) = 2,796 bytes，位于打开期缓存，不压任务栈。比赛遮挡缓存也从常驻实例移至打开期内存，关闭 App 时释放。

主机实测结构大小（不是设备空闲内存）：

| 项目 | R18 | R19 |
| --- | ---: | ---: |
| GarageRenderer 常驻 | 3,000 B | 3,000 B |
| RaceRenderer 常驻 | 39,352 B | 3,216 B |
| 车库打开期缓存 | 528,408 B | 591,128 B |
| 比赛打开期缓存 | 418,864 B | 481,584 B |

打开期缓存合计 1,072,712 B；常驻合计 6,216 B。相对 R18，二者合计净增加 89,304 B。

- 28 套 ASan／UBSan 主机回归通过：12 游戏、15 Vector Run、Launcher；生产渲染检查通过。
- 384 场策略比赛、64 组长跑、既有裁剪／实体车测试通过，车型策略胜场不变。
- ESP-IDF 构建通过：镜像 `0x4a2860`，分区余量 `0x4d7a0`（6%）。未升级依赖。
- `git diff --check` 通过。仅本地提交，未推送、未烧录。

新扫描行深度算法的设备耗时仍须实测，不能由主机通过推断 30 FPS。重点验收四车桥下、红蓝弯道贴墙、低画质保留遮挡、AMOLED 暗部可见度与退出后的内存回收。
