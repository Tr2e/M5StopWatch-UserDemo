| G1 状态 | 生产落点 | 结论 |

| InputCheck | 校准页顶部输入源、`INPUT OFFLINE`、端口/地址原因与退出路径 | 与 Calibration 合并，不增加无意义确认步骤 |
| Calibration | 居中层级、稳定指令、进度、倒计时和失败等待 | 已真机通过 |
| Flight | 显式峡谷、战机、HUD、速度、姿态和推进 | 已真机通过 |

## 不继续实现的项目

- 不添加第二层 App 标题/开始页：Launcher 已完成身份与启动动作，内部重复只会延长进入。
- 不显示成绩、射击、护盾或能量：当前没有对应玩法模型，HUD 不展示伪数据。
- 不加入纯装饰性启动扫描、随机字符、白闪或 CRT 噪点。
- v1 不采用声音/振动：尚未定义安全、功耗和用户关闭策略，不与 UI/HUD 收尾混合。

## 交接门禁

- [x] 常驻 HUD 字段均有真实数据源。
- [x] 世界、战机、HUD 和相机坐标系职责清晰。
- [x] 巡航、Boost、转向、俯仰、风险、碰撞、暂停、失联和双视角均有真机证据。
- [x] 速度、AGL、航向、俯仰标签和风险数字在固定圆屏安全区内。
- [x] 低细节保护不会删除战机、峡谷主网格、远景、HUD 或风险。
- [x] 默认外设开关仍为 `0`，未越过电气验收门禁。
- [x] 用户确认 UI/HUD 阶段收尾并进行阶段性提交。G4-P5 因实体线束与电气条件尚未具备而留待后续推进。

## 结论

UI/HUD 已经从“继续添加细节”转为“保护已确认基线”。H10 通过后，除非真机发现具体缺陷，不再主动修改地形、战机、HUD 布局或颜色。下一阶段必须从已形成的电气文档开始，逐项验证线序、短路、电压和地线，不允许为了加快进度直接启用 `VECTOR_CANYON_USE_EXTERNAL_INPUT`。
