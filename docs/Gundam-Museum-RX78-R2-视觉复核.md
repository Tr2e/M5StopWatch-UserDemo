# RX-78-2 R2：对照实物后的修订

2026-09-13，`feat/gundam-museum`，基于 R1 提交 `ed0f635` 的工作区修改。R1 的可辨识结构和美术质量不足；自动检查通过不等于忠实还原。R2 修正一批明显错误，仍属于需要继续造型打磨的低模样机，未标记为实物还原验收通过。

后续精修见 [R3 官方多图校准记录](Gundam-Museum-RX78-R3-官方多图校准.md)。本卡和 v2 图片保留作历史基线。

## 对照方法与发现

再次打开 [万代 HGUC 191 官方说明书](https://manual.bandai-hobby.net/pdf/1004.pdf) 第 1 页的成品照、第 2 页头部/胸部/四肢拆件图、第 4 页脸部与装备参考。实际看了成品脸部裁剪放大图；官方照片帮助判断外轮廓，拆件图用于确认面罩、颈圈、肩甲、膝踝和喷口的连接关系。没有从板件数量推断渲染面数。

官方成品照是透视照片且站姿不同，因此只用于外观核对，没有用两张不同姿态的图片计算虚假的相似度分数。临时三栏对照图位于 `/private/tmp/gundam-r2-reference-comparison.png`：左栏为官方照片裁剪并等比缩放，另外两栏保留原生 468×466 的 R1/R2 游戏画面。原始 PDF 和页面渲染也保留在本机临时目录。官方图片未加入游戏或版本化资源；版本化 `rx78-before-after.png` 仅含本项目生产渲染。

R1 的主要偏差及 R2 对应修订：

- 腿：并拢且近似等宽的双腿使剪影失真。现在从髋部旋转整条腿，略外展、脚尖外转；重做小腿上部鼓起、下部收窄的轮廓，膝甲和胫甲采用宽面收尖的结构；加入踝侧圆轴、调整脚面和红色鞋头。
- 胸腰：原来的胸部像平面蓝色方块。增加胸壳向外、向前的折面，保留格栅凹口，重做中央驾驶舱盖的前后层次；前裙甲向下外张，中央红色块移回腰带位置，缩短原先夸张的红色裆部。
- 肩臂：肩甲由宽平盒体改为下缘收斜的外壳与前片，手臂略外展，前臂靠肘部较厚、朝腕部收窄。
- 头：移除凸出的黑色眼罩，头盔前部留出面部开口；眼睛位于斜眉下，面罩改为纵向折面与两条横向折线槽，缩短红下巴。侧面三条外贴灰条改为四组嵌在斜面上的通风纹；额侧加入火神炮口。V 天线收窄，颈圈补上向后上升的两侧和前部横肋。
- 盾和枪：盾面加宽、加长，轮廓和十字随之调整；步枪改为向外倾斜的持握角度。步枪主体仍是简化形状，不能认为已经完成武器复刻。
- 光照：调整按面计算的主光、环境光和背部补光，让装甲折面在正面和背面保留明暗。仍没有纹理烘焙、阴影或真实材质。

## 结构与生产显示复核

所有游戏图均来自同一个生产 C++ 模型、Mini 4WD 软件光栅器和原有相机参数。没有改 UI、换取景大小、修图或用效果图掩盖模型问题。

实际查看了正面、背面、左右侧、俯视、灰模、装备视图和头部特写。与 R1 同相机的两栏图显示站姿、胫甲、面罩和盾牌变化；头部特写同时暴露了仍存在的低模折面和头盔曲率差距。原生全身图中面部只有少量像素，不能据此代替头部特写审查。

本轮在删面检查中发现并修复：

- 头盔的开放面罩暴露内侧，薄面片和面部装饰需要保留双面语义，不能沿用封闭外甲的剔除规则。
- 原先可省的颈部端盖在新面部结构下可能可见；保留这些端盖。站姿改变后髋部端盖也保留，不继续使用旧的 72 面删减结论。
- 一个仰视角在手臂旁的空隙里暴露喷口后缘。逐面诊断定位到喷口外壁，补上其后端环形封口；没有通过放宽像素检查来忽略缺面。

没有修改共享光栅器，也没有扩大原先掠射角剔除保护区。

## 本轮验证与预算

`SANITIZE=1 bash tools/test_gundam_museum.sh /private/tmp/gundam-r2-e` 通过：864 组视角/装备/特写/分辨率组合，埋藏面有无和局部/完整重画均为 0 像素差；剔除前后总计 45 个边界像素差，单帧最多 2 个，内部差异为 0。几何、法线、容量、控制和反复打开关闭检查通过。

当前装备模型为 2,238 panels，正常生成省去 48 个已验证的埋藏端盖，诊断补回后 2,286；容量由 2,048 调至 2,560。主机 `workingBytes()` 从 559,160 B 增至 597,048 B，增加 37,888 B。默认视角剔除 1,066、提交 1,172；采样视角平均剔除约 47.27%。本轮优先修正外形和可见缺面，**没有声称总面数或内存比 R1 更少**。

目标固件编译通过，大小 3,930,912 B，OTA 分区仍余约 24%。校验值和模型源文件哈希见 `assets/gundam-rx78-v2/firmware.json`。当前工作区仍包含用户已有的 Mini 4WD 首页改动，固件未烧录。

## 尚存差距

R2 仍有明显的低模折面；头盔曲率、肩甲局部倒角、胸部复杂曲面和步枪轮廓尚不及实物。固定站姿也未复现参考照片的完整关节角度。下一步造型验收应继续按同一套官方成品参考核对这些部位，而不是把增添细节、面数或测试通过当作还原完成。真实屏幕亮度/材质观感、持续帧时间和实际堆余量仍需设备测量。
