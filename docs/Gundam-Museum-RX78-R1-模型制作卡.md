# RX-78-2 / HGUC 191 首台展示样机

日期：2026-09-13。分支：`feat/gundam-museum`。基于 `6b9512f`，保留进入任务前已有的 Mini 4WD 首页及其他工作区改动。

## 任务、版本与坐标

制作独立的 Gundam Museum App，先验证 RX-78-2 素体、持枪持盾和头部特写；触屏旋转、自动巡展、机身按键可用。第一版是固定站姿的低多边形展示模型，尚未加入自由关节编辑、系列收藏存档或外设控制。

参考锁定 **HGUC 1/144 RX-78-2，2015 年版本（HGUC 191）**。不是 RG 2.0、MG 3.0，也不是直接导入官方 CAD。源模型为手工参数化 C++，比例来自官方成品图观察，未将推断坐标写成实测毫米。

`+Y` 向上，`+Z` 朝正面，`+X` 是机体左侧；脚底 Y≈0。相机绕全身 Y=1.68 / 头部 Y=2.97 的观察中心旋转，俯仰范围 −0.20…0.70rad。取景尺度固定，旋转过程中不按投影包围盒反复伸缩。

## 结构与材质决策

腿部：红色脚底/鞋头、白色脚面、独立踝甲、关节圆柱、分段小腿与正面折脊、独立膝甲、大腿外甲。保持双腿之间的空隙。

躯干：白色分块裙甲和黄色块、红色中央裙甲与腹部、蓝色胸壳及中央突出结构。胸口用深色口腔和独立三层黄色格栅，主要部件没有靠黑色贴纸伪造空区。

头部：分段头盔、黑色眼部底面、黄色眼睛、凸出的白面罩、红下巴、脸侧三道通风纹、前后摄像器色块、具有厚度和背面的 V 天线。首轮将天线从宽三角片修成细长棱片，并收窄眼睛高度。

手臂：独立肩甲、上臂、肘轴、前臂与深色手部。武器为固定挂接的站姿展示；当前不声称有完整关节骨架或动态装配。

背包与装备：保留双喷口的环形口沿、内壁和退后的黑色底；两支剑柄；步枪的机匣/枪管/瞄具；盾牌的白边、红面、黄色十字和背部横/纵肋及挂接块。没有使用透明材质层。

全部面片以 RGB565 Solid 材质通过现有 Mini 4WD 软件光栅器绘制。照明为每面计算的固定方向明暗；没有外部纹理解析、逐像素 PBR 或动态阴影。原生界面文字不随模型渲染比例降采样。

## “看不见的渲染”的处理

1. **从资产中不创建拼装专用内构。** 插销、卡扣、装甲内部加强筋、PC 件完整内部形状及备用手型等不进入展示网格；关节外露部分和可见喷口内壁仍保留。这是创作选择，没有虚构“自动删除多少官方零件”的统计。
2. **省去埋藏端盖。** 脚踝、髋部、颈部、肩部和腕部连接圆柱的端部嵌入相邻部件，正常生成路径跳过共 72 个端盖 panel。`keepBuriedFaces` 诊断路径会重新生成这些面，以实际画面对照证明本次采样范围内删面无变化。
3. **闭合外甲背面剔除。** 每个 panel 保存单位法线；相机侧检查通过后才送入投影/栅格。刻意留一个小的掠射角保护区。小型表面标记及喷口底片用明确的双面标记，不能把这类薄面当作闭合外甲剔除。
4. **屏外面片跳过光栅。** 投影后的面片包围盒与模型窗口不相交时跳过填充；头部特写尤其受益。
5. **局部重画/送显。** 连续展示时更新 `(40,100,width−80,288)`，保留顶部与底部控件。进场和 AUTO/STOP 状态改变整页更新；画布与直接 framebuffer 均有对应路径。

没有按“正面截图看不到”永久删除背包或背甲。新增模型不改变赛车的全局剔除策略，继续直接调用赛车生产 `CarSurfaceRaster` 和 `mesh_parts::Builder::quad`，没有复制出第二份光栅器。

## CR1：结构审查及修复

- 首版过多三角形端盖触发容量溢出：把凸八边形封口和圆柱端盖合成凸四边形；明确容量溢出必须失败，不允许静默缺武器。
- 装甲截面的宽/深同时变化会产生非平面角部四边形：生成时检测并拆为独立三角形，每片都有准确的剔除平面。
- 腕关节下端最初未完全进入手部：延长进入手部的部分，确保其端盖可以安全省略。
- 天线过宽、眼睛过高：对照官方头部近景，修成更细的有厚度天线、降低眼睛高度。
- 保留后视喷口、手臂/躯干与双腿间隙，素体和装备版分别生成和核对。有限多视角检查不是任意几何相交的解析证明。

## CR2：生产显示及修复

- 使用实际生产 C++ renderer 生成全身、正背侧、另一侧、俯视、灰模、交互降采样与头部特写，已打开查看。
- 直接对所有面使用单面剔除时，眼睛等薄面在侧视出现消失：给薄表面显式双面语义，保留外甲剔除。
- 逆深度量化下背面可能在等深边缘覆盖前面：诊断路径先画背面再画正面，避免把后画的不可见面当作正确外观基线。
- 头部特写的胸部曾干扰底部机体名：给名牌加不透明背景；底部操作文字过长，缩短至圆屏安全区内。
- 局部重画与完整重画逐像素一致；换模式与恢复清晰度不会留下上一帧机体轮廓。

## 验证记录

主机最终 ASan/UBSan：**864 组**，包括素体/装备、全身/头部、3 个俯仰、24 个方位和 65%/90%/100% 绘制比例。

- 埋藏面有/无：**0 像素差异**。
- 局部/完整重画：**0 像素差异**。
- 背面剔除：平均约 **49.15% 的 panel 不提交光栅**。这是测试姿态下的提交量比例，不是 GPU 指标或实测提速比例。
- 剔除前后共 **123 个颜色像素差异**，其中 106 个为覆盖差异；单帧最多 8 个差异像素。差异都限制在一个内部采样像素对应的边界范围内（低分辨率放大后最多两屏幕像素宽），**没有变化深入轮廓内部**。不宣称剔除逐像素完全相同，也不把采样检查当作任意视角证明。
- 输入：慢帧完整触摸手势、单次消费、俯仰限位立即反向、复位取消旧手势、输入失效取消、模式循环、自动巡展接管/中断、返回和时间回绕均通过。
- 重入：renderer 分配/释放循环 10 次通过主机 sanitizer。
- 共用回归：`CXX=/private/tmp/gundam-host-cxx SANITIZE=1 bash tools/test_lets_and_go.sh` 全部通过，含赛车、机身输入、Vector Run、Launcher 和生产 renderer。临时编译器包装仅补入现有 M5GFX 字体路径，未改旧游戏源码。
- 证据清单：10 个必需视角，`check_evidence.py` 通过；自动巡展 GIF 从同一生产 renderer 的 48 帧编码，不是设备录像或实时帧率证明。

制作中确实检查并修复了失败结果；最终可交付图片不包含失败阶段调试图。

## 预算与边界

持枪持盾版 **1,818 panels**；诊断补回端盖为 1,890，容量为 2,048。默认相机剔除 918、提交 900。几何有效性、各部件存在、法线单位长度和无溢出断言通过。

主机打开期 `MuseumRenderer::workingBytes()` 为 **559,160 B**，大对象放在堆中，关闭释放；该值不是 ESP32 实时峰值。RGB565 颜色/深度工作区仍为 352×288，渲染过程中不逐帧分配模型。

触屏与机身 GPIO 沿用 Mini 4WD 独立后台采样；当前不启动 Grove 外设，不声称 Joystick2 / Dual Button 接入。A 短按或屏幕左右箭头循环视图，B 或 RESET 复位，A 长按或左上返回退出，AUTO/STOP 切换巡展，拖动可接管自动旋转。

当前固件构建及校验值见 `assets/gundam-rx78-v1/firmware.json`。本次未烧录：AMOLED 观感、持续旋转帧时间、按键触屏端到端延迟、实际内存余量与跨 App 真机重入均待设备验收。
