# R6 三圈比赛模拟评审

## 本轮交付

- 完成最多四车的 60 Hz 固定步比赛控制器。
- 对手依玩家选择生成，玩家始终位于数组及发车位最后一格。
- 初速由可复现种子生成，对手偏差小于约 3%，玩家初速固定更低。
- 玩家前 2.5 秒使用 90% 马达效率，之后恢复，形成倒数追逐开局。
- AI 根据曲率选择走线、检测前车并尝试从空侧超越。
- 完成轻量车辆接触、三圈计数、最佳圈、冲线顺序和实时名次。
- 状态机自动串联发车介绍、三秒倒计时、比赛、冲线与结算。

## 自审 A：正确性与架构

发现并修正：

1. ESP32 工具链中 `uint32_t` 与无后缀模板推导类型不同，显式固定 `std::min<uint32_t>`，消除只在交叉编译出现的错误。
2. 已冲线车辆原本仍可能参与后车接触；碰撞阶段现在跳过未激活和已完成车辆，保护冲线快照。
3. Joystick2 连续失效超过 600 ms 时状态机自动进入暂停并冻结模拟；恢复连接后仍需玩家主动继续，避免无控制自动起跑。
4. 名次使用未回绕的赛道距离，立交平面交叉和起终点回绕不会制造假超车。

## 自审 B：公平性、性能与极端路径

1. AI 追赶只提供每个名次 0.6%、最高 1.8% 的效率修正，领先者轻微降 0.4%；最后半圈全部关闭。
2. 单帧最多补算 5 个固定步，剩余积压丢弃并饱和记录，避免慢帧雪崩。
3. 比赛控制器常驻状态限制在 2048 字节内，渲染快照限制在 320 字节内，无逐步动态分配。
4. 同一种子连续运行得到相同比赛时长、名次和最佳圈；0 对手和 3 对手均有覆盖。

## 验证结果

- 比赛模拟严格编译：通过。
- AddressSanitizer + UndefinedBehaviorSanitizer：通过。
- 120 秒模拟上限内完成三圈：通过。
- 同种子可复现结果：通过。
- 单人模式、玩家末位和慢帧补步门禁：通过。
- ESP-IDF 修正后首轮构建：通过，镜像 `0x495400`，应用分区剩余 `0x5ac00`（7%）。
- 两轮修正后的最终构建：通过，镜像 `0x4954f0`，应用分区剩余 `0x5ab10`（7%）。

## 真机延后项

- 2.5 秒追逐窗口是否足够明显、AI 超车观感、护墙/车辆碰撞手感。
- 60 Hz 模拟与 30 FPS 绘制同时运行时的真实帧耗。
