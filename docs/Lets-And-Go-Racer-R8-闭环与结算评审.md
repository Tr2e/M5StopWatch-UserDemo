# R8 全流程闭环、结算与持久化评审

## 本轮交付

- 结算页显示最终名次、总用时和当场最佳圈。
- 结算菜单提供 `RETRY`、`GARAGE`、`EXIT`，支持摇杆环绕选择与 Blue 确认。
- `RETRY` 保留车辆、对手、赛道和随机种子；`GARAGE` 清空对手并回到选车；`EXIT` 回 Launcher。
- NVS 保存最后确认的赛车和 `SKY LOOP 01` 本地最佳圈。
- 存储结构带版本号、尺寸检查、车型合法性和圈速范围修复。

## 自审 A：状态与生命周期

发现并修正：

1. 菜单轴连发器曾在比赛状态继续吸收转向，进入结算页时可能继承按住状态而误移动；现在只在选车、选对手和结算三个页面启用，其他状态主动复位。
2. Retry 重新调用 `RaceController::prepare` 但保留 `_raceSeed`；回车库则把种子清零，下一场才生成新种子。
3. 结算 Red 返回与 `GARAGE` 行为一致，均同步车库游标并清理对手。
4. `onClose()` 依次关闭输入任务、两个渲染器和状态，再恢复 LVGL；所有 close/reset 操作可重复调用。

## 自审 B：存储与视觉

发现并修正：

1. 选车保存入口由两处重复代码收敛为一个函数，相同车型不重复写 NVS。
2. 仅车型字段损坏时改为字段级修复，保留仍有效的最佳圈；版本不兼容才整体恢复默认。
3. 只有新纪录才写最佳圈，写入或提交失败会留下日志，不阻断游戏流程。
4. 结算按钮全部位于圆屏安全区，当前选项用玩家车辆官方强调色描边。

## 验证结果

- 结算动作、环绕选择和状态转移严格编译：通过。
- 结算/持久化逻辑 sanitizer：通过。
- 旧状态机回归：通过。
- ESP-IDF 首轮构建：通过，镜像 `0x497330`，应用分区剩余 `0x58cd0`（7%）。
- 两轮修正后的最终构建：通过，镜像 `0x497400`，应用分区剩余 `0x58c00`（7%）。

- 结算字体、选项间距和摇杆选择手感。
