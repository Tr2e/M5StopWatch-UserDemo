# Gundam Museum · RX-78 隐藏线显示

## 范围

用户要求去掉 RX-78 着色、改成隐藏线；扎古、沙扎比、命运暂时不进入浏览。几何、比例、站姿和装备未改。牛高达与强袭仍为原来的分面着色。

实心基线仍是 `docs/assets/gundam-sd-rx78-v5` 与 `docs/assets/gundam-cubic-space-20260915/rx78`，本轮不覆盖。

## 实现

- 生产光栅器先按原深度填充房间纸色 `0xdefb`，再描可见板件外缘。远侧边不画；房间网格被机体轮廓挡住，不会从装甲里透过来。
- 仅 `ModelId::Rx78` 走这条通路。线色用导航灰 `0x4208`。
- 转圈时仍做隐藏线：65% 填纸色和深度挡住背面，再近邻放大到 424，按全分辨率描去重可见边，细线不跟着放大发糊。牛高达/强袭仍用原来的 65% 拖动。
用户后来要求 RX-78 恢复着色，隐藏线改到牛高达，并隐藏强袭。见 `docs/Gundam-Museum-Nu-隐藏线-20260918.md`。

实际查看正/侧/背/俯、完整装备、头部特写和 65% 拖动：正面可读，头壳曲面因原有分段显得密，这是网格边而不是套件外轮廓。
