# R3 车库、展示与对手选择评审

## 本轮交付

- 完成玩家赛车选择、环绕游标与确认流程。
- 完成选车后的局部放大、轮胎旋转、车体振动和风线动效。
- 完成 0–3 名对手的选择、取消与单人模式入口。
- 完成纸张底色、铅笔轮廓和官方识别色组成的手绘车库界面。
- 车库逻辑保持为纯 C++，可脱离设备进行严格编译和 sanitizer 测试。

## 自审 A：正确性与交互

发现并修正：

1. 白色车体若直接使用近白色 RGB565 描边，会与纸张底色混在一起。车体改为铅笔色轮廓，以留白表示白色涂装，官方颜色只用于装饰线。
2. `moveRival(0)` 在游标恰好与玩家车重合时存在不终止的理论风险。增加零方向保护和至少两台车的编译期约束，并补充回归用例。
3. 对手游标始终跳过玩家赛车，`DONE` 入口在正反两个方向都可到达；验证了零对手直接确认的单人流程。

## 自审 B：性能与资源

发现并修正：

1. 原实现缓存四台展示级线框，应用常驻时约占 16 KiB；改为只缓存当前赛车，且仅在游标换车时重建。
2. 原实现为每个线段端点重复计算车身和车轮三角函数；改为每台车每帧各计算一次，再复用于所有线段。
3. 展示级线框仍采用固定容量数组，渲染热路径无动态分配。

## 验证结果

- 车库选择测试：`-Wall -Wextra -Werror -pedantic` 通过。
- AddressSanitizer + UndefinedBehaviorSanitizer：通过。
- R1 状态机回归：通过。
- R2 车辆几何回归：通过。
- ESP-IDF 首轮完整编译：通过，镜像 `0x4929d0`，应用分区剩余 `0x5d630`。
- 第二轮修正后的最终固件编译：通过，镜像 `0x492a00`，应用分区剩余 `0x5d600`（7%）。
