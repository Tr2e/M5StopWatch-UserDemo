# Vector Canyon Fighter：G4-H3 中央飞行符号评审

> 日期：2026-09-05
>
> 范围：地平线、俯仰梯、route cue 与第一人称机体基准的视觉层级和安全裁切。外围速度/AGL/航向/状态区不在本阶段调整。

## 原问题

- ±5°、±10°俯仰线均使用相同连续线型，标签又只显示绝对值，玩家需要依赖位置猜测正负方向。
- 所有非零俯仰线共用同一低亮颜色，近级与远级没有层级。
- 俯仰标签直接写入投影坐标，第一人称大俯仰或滚转时可能进入侧边仪表、顶部航向区或圆屏裁切区。
- route cue 使用真实远端航道投影，但投影离开中央净空时会直接消失，无法继续提供回正方向。

## 设计决策

1. 零度地平线保持最亮、最长，并继续由实际相机对世界水平面投影。
2. ±5° 使用中亮度，±10° 使用低亮度；不额外增加梯级数量。
3. 正俯仰线保持连续，负俯仰线改为规则短划线；数字显示 `+5/+10/-5/-10`。
4. 梯级线仍允许由显示驱动自然裁切，但标签只有落入中央文字安全区时才绘制：第三人称下避开战机与横向偏移尺，第一人称下可使用更大的下半屏空间。
5. route cue 沿“相机主点 → 原始投影点”的射线约束在中央导航安全框内，保持方向不变；被约束时增加一枚短方向尾标，明确它是边缘引导而不是精确投影位置。
6. 第一人称 W 形机体基准继续固定在相机主点；第三人称继续由可见战机本体承担基准，不恢复重复符号。
7. 追尾相机维持已通过的上三分之一地平线；第一人称相机使用独立的 `0°` 中立俯仰与 `0.50×height` 主点，使初始地平线精确位于屏幕中心。
8. 第一人称 route cue 与中心机体基准距离小于 `14 px` 时隐藏，出现可读航道偏差或进入边缘引导后再显示；横向偏移尺下移至 `y=330`。
9. 战机仍位于 `y=304`，初始高度、上下飞行范围、相机高度和碰撞边界不变；避免为第一人称构图破坏已通过的第三人称触地关系。

## 不变项

- 不单独放大 HUD 的 pitch/roll，不破坏 H1 世界共形关系。
- 不把 route cue 改称速度矢量。
- 不移动速度、AGL、航向、滚转刻度、横向偏移尺和底部状态区。
- 不修改地形、碰撞、飞行模型、输入映射、战机与尾焰。
