# Vector Canyon Fighter：UI / UE 设计基线

> 阶段：G1（UI / UE）
>
> 依赖：[项目设计与执行计划](Vector-Canyon-Fighter-项目设计与执行计划.md)
>
> 本文只定义玩家可见的画面、状态和体验反馈；不规定渲染算法、类结构或外设驱动。

## 1. 体验命题

玩家看到一架原创未来机甲战机，以第三人称追尾镜头穿过巨大的线框峡谷。战机不是 HUD 图标，也不是第一人称座舱；它是画面中的飞行主体。峡谷尺寸显著大于战机，速度感来自环境相对战机掠过，而不是持续放大战机或剧烈摇镜头。

画面应像一台早期未来飞行模拟器正在计算几何空间：黑色负空间中只有必要的地形线、战机轮廓、推进火焰、航道和少量可读状态。

## 2. 圆屏构图

以 466×466 逻辑画布为基准。核心内容安全圆半径为 202 px，距离圆周至少保留 31 px；其外区域只能容纳可裁切的环境线，不放关键文字或触控目标。

```text
                  [状态弧：模式 / 连接]
                         远方消失点
                    ┌──── 航道预判区 ────┐
                 峡谷壁                    峡谷壁
                       中距离地形/障碍

                           战机
                     （下中部，小尺寸）
                  [速度/推进]   [姿态/风险]
```

### 2.1 空间分区

| 区域 | 范围 | 内容 | 禁止事项 |
| --- | --- | --- | --- |
| 远距区 | y=78–174 | 消失点、航道轮廓、远处峡谷口 | 放置密集 HUD 或粗线 |
| 预判区 | y=150–294 | 可见坡面、转弯、门洞和风险 | 被战机或文字遮挡 |
| 战机区 | x=190–276，y=292–378 | 战机、喷口、短航迹 | 战机大到遮住航道 |
| 近景区 | y=300–430 | 快速流动的地面/峡谷边线 | 高密度文本和长期高亮 |
| 状态区 | 顶弧与下侧两角 | 模式、速度、推进、风险 | 与环境使用相同最高亮度 |

战机正常翼展为可见圆直径的 12–18%，约 49–73 px；战机中心基准位置为 `(233, 335)`。高速不放大战机，只增强环境推进与喷口反馈。

## 3. 主场景视觉语法

### 3.1 战机

- 原创的紧凑双发战机轮廓：尖锐座舱、明显主翼、双喷口、垂尾/小翼和有限的机甲分层。
- 主体默认使用低亮度深蓝灰填充或负形；外轮廓为冷白/蓝青线框，不能与峡谷主线同色同亮。
- 喷口是唯一持续的动力锚点：巡航为短而弱的蓝紫/青白，推进为长度和明度上升的暖橙或白色核心。
- 滚转只改变战机和少量追尾镜头响应；最大视觉倾角为 ±18°。俯仰只在机鼻、翼面和地形垂直位置上表达，避免整屏翻转。

### 3.2 峡谷与航道

- 峡谷由纵向壁线、横向截面和地面网格组成；近景线疏、粗、快，远景线细、密、慢。
- 线框必须服务于透视、坡度、可飞行空间或危险，不能作为随机背景纹理。
- 航道不是恒定直廊：用渐变宽度、坡面、转折、岩柱/门洞形成可预判风险。
- 环境默认色为低饱和青绿；最高亮度只给即将碰撞的边界或短时推进反馈。

### 3.3 HUD

HUD 是安静的仪表层，不是边框装饰。

| 元素 | 默认位置 | 内容 | 状态语义 |
| --- | --- | --- | --- |
| 顶弧状态 | 顶部安全区 | `VECTOR RUN` / 输入源短名 | 稳定身份，不参与闪烁 |
| 速度 | 左下安全区 | `SPD 072` 等宽数字 | 数值与速度条同向变化 |
| 推进 | 速度下方或邻近 | `CRUISE` / `BOOST` | 推进时才使用强调色 |
| 姿态提示 | 右下安全区 | 小型滚转/俯仰参考 | 只作参考，不替代战机姿态 |
| 风险 | 预判区边缘 | `TERRAIN` + 箭头/包络线 | 文字、形状、颜色三重编码 |

不显示假坐标、随机编号、无来源规格或持续扫描线。

## 4. 色彩、线条与字体令牌

具体实现色值可在 G2 调整，但语义不得变化。

| 令牌 | 设计意图 |
| --- | --- |
| `surface.base` | 近黑而非纯黑，保留暗部层次 |
| `terrain.primary` | 青绿线框峡谷与航道，结构最高对比度 |
| `terrain.secondary` | 次级截面、远景网格和参考线 |
| `ship.primary` | 冷白/蓝青战机主轮廓，区别于地形 |
| `state.active` | 推进、已确认、当前输入源；同屏一个主要强调色 |
| `state.caution` | 即将接近地形；配合包络形状和文字 |
| `state.fault` | 失联、校准失败；包含原因与恢复动作 |

线条按四级处理：L0 为可移除远景纹理，L1 为次级地形，L2 为峡谷主结构/战机轮廓，L3 为短时推进或风险。发光只能由既有几何线派生，不能覆盖小字号和端点。

字体采用紧凑无衬线；速度和读数使用等宽/表格数字。标签短且确定，如 `CALIBRATING`、`INPUT: IMU`、`JOYSTICK LOST`、`TERRAIN`。

## 5. 状态与用户旅程

```text
Title → InputCheck → Calibration → Flight ⇄ Pause
                                      ↓
                              Risk / Impact → Retry
```

| 状态 | 首屏信息 | 用户动作 | 正常退出/恢复 |
| --- | --- | --- | --- |
| 标题 | 战机剪影、`VECTOR RUN`、开始提示 | A/B 或触摸开始 | 进入输入检查 |
| 输入检查 | 当前输入源、连接/失联、简短提示 | 继续或使用 IMU | 完成后校准 |
| 校准 | 中性姿态目标、稳定进度 | 保持水平/确认 | 进入飞行；失败可重试 |
| 飞行 | 战机、峡谷、速度、推进、风险 | 控制姿态与速度 | 暂停、风险或撞击 |
| 暂停 | 冻结但可见的场景、继续/退出 | 恢复或退出 | 回到飞行或标题 |
| 风险 | `TERRAIN`、方向与剩余余量 | 修正姿态/减速 | 风险消失或进入撞击 |
| 撞击/重试 | 清晰结果与本次距离/成绩（如采用） | 重试或退出 | 回到校准或标题 |
| 外设失联 | `JOYSTICK LOST`、已切换/可切换输入 | 确认 IMU 或重连 | 安全中性后回输入检查 |

## 6. 动效与飞行反馈

| 事件 | 画面反馈 | 时长/限制 |
| --- | --- | --- |
| 启动 | 环境线由远至近建立，战机从暗轮廓变为可读状态 | 不超过 600 ms；不可阻塞输入 |
| 巡航 | 地形切片稳定推进，喷口低振幅 | 低频、无随机闪烁 |
| 加速 | 近景切片速度增加，喷口延长，速度数字收束至目标 | 120–220 ms 的可逆过渡 |
| 转向 | 战机先滚转，峡谷消失点随后侧移 | 最大视觉滚转 ±18° |
| 爬升/俯冲 | 机鼻姿态、地面距离与前方坡面共同变化 | 不用整屏旋转表达 |
| 风险 | 危险边界短时加强 + `TERRAIN` + 指向 | 有停止条件，不持续高频闪烁 |
| 撞击 | 环境推进停止、战机失去推进、结果层出现 | 避免长时间白闪 |

## 7. 输入体验映射

在没有外设时，以 IMU + 表身按键构成完整可玩闭环；外设接入后只替换手势来源。

| 飞行动作 | 临时输入 | 最终输入 | 屏幕反馈 |
| --- | --- | --- | --- |
| 横向转向 | 表身左右倾斜 | 摇杆 X | 战机滚转、峡谷侧移 |
| 爬升/俯冲 | 表身前后倾斜 | 摇杆 Y | 机鼻与地面距离变化 |
| 巡航速度 | K1 短按调低、K2 短按调高 | Dual Button 调低/调高 | 速度读数与推进长度 |
| 推进 | K2 按住 | 摇杆按下或约定键 | `BOOST` 与喷口脉冲 |
| 沉浸/视觉模式 | 正常飞行中 K1 长按 | 后续外设映射可选 | 隐藏/恢复战机、尾焰、投影与频闪，峡谷和 HUD 保持运行 |
| 撞击后重开 | K1 长按 | 双键组合或约定键 | 返回校准后重新开始 |
| 返回 Launcher | K1+K2 长按，保留系统约定 | 表身按键组合 | 退出当前应用 |

K1 的长按语义由应用状态区分：正常飞行切换沉浸模式，碰撞后进入重新校准；两条路径均不得触发暂停副作用。外设接入时只替换飞行动作来源，不得破坏 K1+K2 返回 Launcher 的既有约定。

## 8. G1 基准画面清单

下列画面将在设计还原阶段逐项对照：

1. 标题：战机剪影与短开始提示。
2. IMU 校准：中性目标、输入来源、可取消路径。
3. 低速巡航：远近线条层级、战机比例与状态区。
4. 高速推进：喷口、切片推进与速度强调。
5. 左转/右转：战机滚转与峡谷消失点位移。
6. 爬升/俯冲：机鼻、地面和坡面关系。
7. 风险：`TERRAIN` 的文字、形状和颜色编码。
8. 暂停：冻结背景、继续/退出。
9. 外设未连接/失联：原因、当前回退输入和恢复动作。
10. 低细节/关闭特效：保留战机、航道、风险、速度和输入反馈。

## 9. G1 审查与校准

### 审查结果

| 检查项 | 结论 | 校准结果 |
| --- | --- | --- |
| 是否误做成第一人称 | 通过 | 明确追尾镜头和下中部战机位置 |
| 战机是否过大 | 通过 | 限定为可见圆直径 12–18% |
| 峡谷是否只是背景 | 通过 | 航道预判、坡面和风险均由地形承载 |
| 是否偏向泛滥复古装饰 | 通过 | 禁用随机数据/扫描线作为信息替代 |
| 是否支持临时与最终输入 | 通过 | 统一动作语义，未绑定硬件细节 |
| 是否覆盖失联与低细节 | 通过 | 已列为独立状态和基准画面 |
