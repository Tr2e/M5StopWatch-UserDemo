# R7 手绘比赛画面与 HUD 评审

## 本轮交付

- 完成跟随玩家的伪 3D 追尾相机和前方 36 段开放赛道绘制。
- 完成左右外护墙、外栏杆、路面横线、固定纸纹和远山线框。
- 四台赛车以 Race LOD、官方强调色和旋转轮胎绘制到赛道标架中。
- 转向姿态、赛道倾角、速度线和撞墙双圈反馈均由模拟状态驱动。
- HUD 包含三圈进度、实时名次、km/h、Boost 能量和带所有车位置的迷你地图。
- 发车末位提示、三秒倒计时、输入失联暂停与冲线覆盖层均已完成。

## 自审 A：正确性与视觉层级

发现并修正：

1. 早期车体变换曾临时复用 `TrackFrame::distance` 存储横向位置，破坏字段语义；改为明确的 `CarPose`，一次计算车体局部横向/前向轴。
2. 车体最初没有使用 `headingOffset`，转向只有位移没有姿态；现在车身随转向角旋转，且底面跟随赛道倾角高度。
3. 迷你地图最初只有赛道线，没有赛车位置；增加玩家实心点和对手空心点，颜色对应官方强调色。
4. 近裁切和视口裁切复用 R4 已测试投影契约，所有赛车与赛道线在进入 M5GFX 前均受限。

## 自审 B：性能与绘制顺序

发现并修正：

1. 路缘计算原先每次调用 `sin(bank)`，同一标架会重复数百次；在 ±0.20 rad 上限内改用小角度近似，误差低于像素可见阈值。
2. 调整为纸面/远山 -> 赛道 -> 赛车 -> 速度线 -> HUD 的固定层序。
3. Race LOD 从通用 144 线容量复制到 64 线紧凑缓存，四车常驻缓存由约 16 KiB 降至约 7 KiB；设 8 KiB 编译期上限。
4. 每帧使用固定 36 个赛道标架和最多四台车，无动态分配；帧率动态降级在 R9 接入。

## 验证结果

- ESP-IDF 首轮比赛渲染构建：通过，镜像 `0x496960`，应用分区剩余 `0x596a0`（7%）。
- R6 比赛模拟严格测试及 sanitizer 回归：通过。
- 两轮修正后的最终构建：通过，镜像 `0x496c00`，应用分区剩余 `0x59400`（7%）。

## 真机延后项

- 追尾相机视角、玩家车可见尺寸、立交前后遮挡和车速感。
- 30 FPS 实际帧耗、米白 AMOLED 功耗、HUD 字体在圆形玻璃边缘的清晰度。
